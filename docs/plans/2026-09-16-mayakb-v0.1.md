# mayaKB v0.1 Implementation Plan


**Goal:** Build mayaKB, a Dockerized knowledge base. Documents go through re-runnable ingestion jobs with swappable connectors, parsers, chunkers, NER and embedders. Search is hybrid, with a dynamic beam and a reranker, and every result carries a citation.

**Architecture:** One Python package, `mayakb`. Ingestion is six job functions. Each reads and writes files in an artifact store, logs to a Postgres `jobs` table, and calls an implementation chosen by name from a registry. Retrieval runs pgvector and Postgres full-text searches in parallel and merges them with RRF. The dynamic beam then prunes the list so only the likely chunks are reranked, and a final cut picks what to return. A Typer CLI drives everything. Docker Compose runs three containers: app, Ollama and Postgres.

**Tech Stack:** Python 3.12, pydantic 2, PyYAML, httpx, numpy, psycopg 3 + psycopg-pool + pgvector, PyMuPDF, python-docx, boto3, spaCy, sentence-transformers, Typer, pytest, moto, ruff. Postgres 17 + pgvector (`pgvector/pgvector:pg17`). Ollama.

**Spec:** `docs/specs/2026-09-16-mayakb-design.md`

## Global Constraints

- Python ≥ 3.12. The package is `mayakb`. Run every command from the `mayaKB/` folder.
- Lines are at most 120 characters. Ruff rules: `E, F, I, UP, B`.
- Unit tests make no network calls, load no models and need no database.
- Postgres tests carry `@pytest.mark.postgres` and use `MAYAKB_TEST_DATABASE_URL`. Point it at a **throwaway** database: the fixture wipes the `public` schema.
- Tests that call real services carry `@pytest.mark.integration`. Each skips unless its variable is set: `LLAMA_CLOUD_API_KEY`, `MAYAKB_TEST_OLLAMA_URL` or `MAYAKB_TEST_RERANKER`.
- Connection details and secrets come only from environment variables, never from KB YAML: `MAYAKB_DATABASE_URL`, `MAYAKB_OLLAMA_URL` (default `http://localhost:11434`), `MAYAKB_DATA_DIR` (default `data`), `MAYAKB_CONFIGS_DIR` (default `configs`) and `LLAMA_CLOUD_API_KEY`.
- Artifacts live at `<MAYAKB_DATA_DIR>/<kb>/<kind>/<id>.<ext>` and are written atomically. Kinds: `raw`, `doc_model`, `chunks`, `entities`, `vectors`, `source_map`.
- Implementation names:

  | Kind | Names |
  |---|---|
  | Connector | `local`, `s3` |
  | Parser | `local`, `llamaparse` |
  | Chunker | `fixed`, `by_section` |
  | NER | `spacy` |
  | Embedder | `ollama` |
  | Reranker | `cross_encoder` |
  | Search backend | `postgres` (`memory` for tests only) |

- Retrieval defaults:

  | Setting | Defaults |
  |---|---|
  | Beam | `policy adaptive`, `depth 50`, `min_beam 5`, `max_beam 30`, `agree_top 20`, `dense_rel 0.9`, `keyword_rel 0.6`, `fallback_widen false`. Fixed baseline: `size 30` |
  | Cut | `min_k 2`, `max_k 10`, `min_score 0.3`, `relative_to_top 0.5` |
  | Other | `token_budget 3000`, `rrf_k 60` |

- Default models: embedder `nomic-embed-text`, reranker `cross-encoder/ms-marco-MiniLM-L-6-v2`.
- Postgres setup:
  - Image `pgvector/pgvector:pg17`.
  - One index table per (kb, embedder, model, dim), with an HNSW cosine index.
  - Set `hnsw.iterative_scan = strict_order` only when pgvector ≥ 0.8.
- Docker setup:
  - Services `app`, `ollama` and `db`, plus a one-shot `ollama-pull`.
  - No published ports.
  - The app runs as non-root uid 10001 with CPU-only PyTorch.
- `mayaKB/` is its own git repository (created in Task 1). Commit at the end of every task, adding the co-author trailer your environment requires.

## Where this plan refines the spec

These refinements are deliberate. Where the plan and the spec differ, follow the plan.

1. `Parser.parse(raw, data)` receives the bytes as well as the `RawDocument`.
2. A `ChunkingStrategy` returns `ChunkPiece`s. The `chunk_document` job adds `chunk_id`, `position`, `doc_id` and `acl`.
3. `DocModel` also carries `source_uri` and `acl`. `doc_id` is always `RawDocument.id` (the content hash), so it stays the same across parsers and chunkers.
4. Identical bytes at two URIs are parsed once, and the citation shows the first URI they were parsed from. The `source_map` artifact (uri → etag, raw id) drives incremental ingest.
5. `Reranker.score` returns values in 0–1. The cross-encoder always applies a sigmoid, because `ms-marco-MiniLM-L-6-v2` is configured to return raw logits.
6. Token counts are approximated as whitespace-separated words, so no tokenizer dependency is needed.
7. `SearchOptions` has `rerank: bool` and `retrievers: hybrid|dense|keyword`, which the evaluation harness needs, instead of a reranker name.
8. `index_chunks` writes to the database, so it decides "already done" from the job log, which lives in the same database.
9. Hybrid retrieval lives in `Searcher._retrieve` (`retrieval/search.py`) instead of a separate `hybrid.py`. New modules the spec didn't list:
   - `core/text.py` and `core/retry.py`
   - `parsers/markdown.py`, `parsers/pdf.py` and `parsers/docx.py`
   - `storage/search/memory.py` (tests only)
   - `wiring.py`, which builds the Postgres runtime from environment settings
10. In KB YAML, the reranker is configured as `retrieval.reranker: {reranker: <name>, ...params}`, or `null` to disable it.
11. Entity filters match normalized text (lowercase, single spaces).
12. Local test databases may have pgvector older than 0.8. In that case the backend warns and skips iterative scans.
13. **Not built in v0.1.** The spec marks these as optional and off by default:
    - HyDE and multi-query expansion.
    - A third retriever that runs NER on the query.

    Entity *filtering* (`--entity`) is built. Both can be added later inside `Searcher.search` without changing any interfaces.
14. **License note:** PyMuPDF (used by the `local` parser) is AGPL-3.0. If that matters, swap the PDF parsing module; it sits behind the `Parser` interface.

`mayakb/core/ids.py`:

```python
"""Deterministic ids: the same inputs give the same id on every machine and every run."""

from __future__ import annotations

import hashlib
import json
from typing import Any


def content_id(data: bytes) -> str:
    """sha256 of raw bytes as hex. Used as RawDocument.id."""
    return hashlib.sha256(data).hexdigest()


def canonical_json(value: Any) -> str:
    """JSON with sorted keys and no whitespace, so equal dicts serialize identically."""
    return json.dumps(value, sort_keys=True, separators=(",", ":"), default=str)


def stable_id(*parts: Any, length: int = 32) -> str:
    """Hash of the parts in order. Strings are used as-is, anything else as canonical JSON."""
    digest = hashlib.sha256()
    for part in parts:
        text = part if isinstance(part, str) else canonical_json(part)
        digest.update(text.encode("utf-8"))
        digest.update(b"\x1f")
    return digest.hexdigest()[:length]
```

`mayakb/core/text.py`:

```python
"""Text helpers. A token is approximated as one whitespace-separated word."""

from __future__ import annotations

import re

_PIECE = re.compile(r"\S+\s*")
_WORD = re.compile(r"\w+")


def count_tokens(text: str) -> int:
    return len(text.split())


def word_pieces(text: str) -> list[str]:
    """Words with their trailing whitespace, so "".join(pieces) == text.lstrip()."""
    return _PIECE.findall(text)


def words(text: str) -> list[str]:
    """Lowercase word characters only, for simple term matching."""
    return _WORD.findall(text.lower())


def windows(n: int, size: int, overlap: int) -> list[tuple[int, int]]:
    """[start, end) windows over n items, each `size` long, overlapping by `overlap`."""
    if size <= 0:
        raise ValueError("size must be positive")
    if not 0 <= overlap < size:
        raise ValueError("overlap must be >= 0 and smaller than size")
    out: list[tuple[int, int]] = []
    start = 0
    while start < n:
        end = min(start + size, n)
        out.append((start, end))
        if end == n:
            break
        start += size - overlap
    return out


def normalize_entity(text: str) -> str:
    """Lowercase with single spaces, so "Acme  Corp" and "acme corp" match."""
    return " ".join(text.lower().split())
```

`mayakb/core/contracts.py`:

```python
"""Data passed between pipeline stages. Every job reads and writes these models."""

from __future__ import annotations

from datetime import datetime
from typing import Any, Literal

from pydantic import BaseModel, Field

ElementType = Literal["heading", "paragraph", "list", "table", "figure", "code"]


class SourceRef(BaseModel):
    """A document a connector can fetch."""

    uri: str
    etag: str | None = None
    modified_at: datetime | None = None
    size: int | None = None


class RawDocument(BaseModel):
    """Metadata for fetched bytes. The bytes are stored next to it."""

    id: str  # sha256 of the bytes
    source_uri: str
    connector: str
    mime: str
    etag: str | None = None
    modified_at: datetime | None = None
    acl: list[str] | None = None  # reserved: principals allowed to read; None = unrestricted
    metadata: dict[str, Any] = Field(default_factory=dict)


class Element(BaseModel):
    id: str
    type: ElementType
    text: str
    page: int | None = None
    section_path: list[str] = Field(default_factory=list)
    level: int | None = None
    bbox: tuple[float, float, float, float] | None = None


class DocModel(BaseModel):
    """The common output of every parser."""

    doc_id: str  # RawDocument.id, so it stays the same across parsers and chunkers
    parser: str
    source_uri: str
    title: str | None = None
    acl: list[str] | None = None
    metadata: dict[str, Any] = Field(default_factory=dict)
    elements: list[Element] = Field(default_factory=list)


class ChunkPiece(BaseModel):
    """What a chunking strategy returns. The chunk job adds ids, position and acl."""

    text: str
    element_ids: list[str] = Field(default_factory=list)
    page_start: int | None = None
    page_end: int | None = None
    section_path: list[str] = Field(default_factory=list)
    parent_id: str | None = None
    metadata: dict[str, Any] = Field(default_factory=dict)


class Chunk(ChunkPiece):
    chunk_id: str
    doc_id: str
    position: int
    acl: list[str] | None = None


class ChunkSet(BaseModel):
    id: str
    doc_id: str
    source_uri: str
    title: str | None = None
    strategy: str
    chunks: list[Chunk] = Field(default_factory=list)


class Entity(BaseModel):
    chunk_id: str
    text: str
    label: str
    normalized: str
    start: int
    end: int
    score: float | None = None


class EntitySet(BaseModel):
    id: str
    chunk_set_id: str
    extractor: str

```python
"""Name -> implementation lookup for every pluggable interface.

Built-in implementations are imported only when first requested, so heavy dependencies
(spaCy, PyTorch) load only when a knowledge base actually uses them.
"""

from __future__ import annotations

import importlib
from typing import Any

KINDS = ("connector", "parser", "chunker", "ner", "embedder", "reranker")

_BUILTINS: dict[tuple[str, str], str] = {
    ("connector", "local"): "mayakb.ingest.connectors.local:LocalConnector",
    ("connector", "s3"): "mayakb.ingest.connectors.s3:S3Connector",
    ("parser", "local"): "mayakb.ingest.parsers.local:LocalParser",
    ("parser", "llamaparse"): "mayakb.ingest.parsers.llamaparse:LlamaParseParser",
    ("chunker", "fixed"): "mayakb.ingest.chunking.fixed:FixedChunker",
    ("chunker", "by_section"): "mayakb.ingest.chunking.by_section:BySectionChunker",
    ("ner", "spacy"): "mayakb.ingest.ner.spacy_ner:SpacyExtractor",
    ("embedder", "ollama"): "mayakb.ingest.embedders.ollama:OllamaEmbedder",
    ("reranker", "cross_encoder"): "mayakb.retrieval.rerankers.cross_encoder:CrossEncoderReranker",
}

_LOADED: dict[tuple[str, str], type] = {}


def _check_kind(kind: str) -> None:
    if kind not in KINDS:
        raise ValueError(f"unknown kind {kind!r}; expected one of {KINDS}")


def register(kind: str, name: str):
    """Class decorator: make an implementation available under `name`."""
    _check_kind(kind)

    def decorator(cls: type) -> type:
        cls.name = name
        _LOADED[(kind, name)] = cls
        return cls

    return decorator


def get(kind: str, name: str) -> type:
    _check_kind(kind)
    if (kind, name) in _LOADED:
        return _LOADED[(kind, name)]
    target = _BUILTINS.get((kind, name))
    if target is None:
        raise KeyError(f"no {kind} named {name!r}; available: {available(kind)}")
    module_name, _, class_name = target.partition(":")
    cls = getattr(importlib.import_module(module_name), class_name)
    _LOADED[(kind, name)] = cls
    return cls


def create(kind: str, name: str, **params: Any) -> Any:
    return get(kind, name)(**params)


def available(kind: str) -> list[str]:
    _check_kind(kind)
    names = {n for (k, n) in _BUILTINS if k == kind} | {n for (k, n) in _LOADED if k == kind}
    return sorted(names)


def unregister(kind: str, name: str) -> None:
    """For tests: forget a registration."""
    _LOADED.pop((kind, name), None)
```

```python
"""Knowledge base config (one YAML file per KB) and runtime settings (environment variables)."""

from __future__ import annotations

import os
import re
from collections.abc import Mapping
from pathlib import Path
from typing import Any, Literal

import yaml
from pydantic import BaseModel, Field, field_validator, model_validator

_KB_NAME = re.compile(r"^[a-z0-9][a-z0-9_-]{0,62}$")

# YAML section -> the key inside it that names the implementation
_SECTION_KEYS = {
    "source": "connector",
    "parse": "parser",
    "chunk": "strategy",
    "ner": "extractor",
    "embed": "embedder",
    "index": "backend",
}


class ImplConfig(BaseModel):
    """Which implementation to use and the parameters to construct it with."""

    name: str
    params: dict[str, Any] = Field(default_factory=dict)


def _to_impl(section: Any, key: str) -> Any:
    """{connector: s3, bucket: x} -> {name: s3, params: {bucket: x}}. Other shapes pass through."""
    if not isinstance(section, Mapping) or key not in section:
        return section
    return {"name": section[key], "params": {k: v for k, v in section.items() if k != key}}


class BeamConfig(BaseModel):
    policy: Literal["adaptive", "fixed"] = "adaptive"
    depth: int = Field(50, ge=1)  # hits per retriever
    size: int = Field(30, ge=1)  # fixed policy only
    min_beam: int = Field(5, ge=1)
    max_beam: int = Field(30, ge=1)
    agree_top: int = Field(20, ge=1)
    dense_rel: float = Field(0.9, ge=0, le=1)
    keyword_rel: float = Field(0.6, ge=0, le=1)
    fallback_widen: bool = False

    @model_validator(mode="after")
    def _check_bounds(self) -> BeamConfig:
        if self.min_beam > self.max_beam:
            raise ValueError("min_beam must be <= max_beam")
        return self


class CutConfig(BaseModel):
    min_k: int = Field(2, ge=1)
    max_k: int = Field(10, ge=1)
    min_score: float = Field(0.3, ge=0, le=1)
    relative_to_top: float = Field(0.5, ge=0, le=1)

    @model_validator(mode="after")
    def _check_bounds(self) -> CutConfig:
        if self.min_k > self.max_k:
            raise ValueError("min_k must be <= max_k")
        return self


def _default_reranker() -> ImplConfig:
    return ImplConfig(name="cross_encoder", params={"model": "cross-encoder/ms-marco-MiniLM-L-6-v2"})


class RetrievalConfig(BaseModel):
    fusion: Literal["rrf", "weighted"] = "rrf"
    rrf_k: int = Field(60, ge=1)
    dense_weight: float = Field(0.6, ge=0, le=1)  # weighted fusion only
    token_budget: int = Field(3000, ge=1)
    beam: BeamConfig = Field(default_factory=BeamConfig)
    cut: CutConfig = Field(default_factory=CutConfig)
    reranker: ImplConfig | None = Field(default_factory=_default_reranker)

    @field_validator("reranker", mode="before")
    @classmethod
    def _reranker_section(cls, value: Any) -> Any:
        return _to_impl(value, "reranker")


class KBConfig(BaseModel):
    kb: str
    source: ImplConfig
    parse: ImplConfig
    chunk: ImplConfig
    ner: ImplConfig | None = None
    embed: ImplConfig
    index: ImplConfig = Field(
        default_factory=lambda: ImplConfig(name="postgres", params={"text_search_language": "english"})
    )
    retrieval: RetrievalConfig = Field(default_factory=RetrievalConfig)

    @model_validator(mode="before")
    @classmethod
    def _flatten_sections(cls, data: Any) -> Any:
        if not isinstance(data, Mapping):
            return data
        data = dict(data)
        for section, key in _SECTION_KEYS.items():
            if section in data:
                data[section] = _to_impl(data[section], key)
        return data

    @field_validator("kb")
    @classmethod
    def _kb_name(cls, value: str) -> str:
        if not _KB_NAME.match(value):
            raise ValueError("kb must be lowercase letters, digits, '-' or '_' (max 63 characters)")
        return value

    @classmethod
    def from_yaml(cls, path: str | Path) -> KBConfig:
        with open(path, encoding="utf-8") as fh:
            return cls.model_validate(yaml.safe_load(fh))


class Settings(BaseModel):
    """Deployment settings. Never stored in KB config files."""

    database_url: str | None = None
    ollama_url: str = "http://localhost:11434"
    data_dir: Path = Path("data")
    configs_dir: Path = Path("configs")

    @classmethod
    def from_env(cls, env: Mapping[str, str] | None = None) -> Settings:
        env = os.environ if env is None else env
        values = {
            "database_url": env.get("MAYAKB_DATABASE_URL"),
            "ollama_url": env.get("MAYAKB_OLLAMA_URL"),
            "data_dir": env.get("MAYAKB_DATA_DIR"),
            "configs_dir": env.get("MAYAKB_CONFIGS_DIR"),
        }
        return cls(**{k: v for k, v in values.items() if v})

    def kb_config_path(self, kb: str) -> Path:
        return self.configs_dir / f"{kb}.yaml"
```

```python
"""ArtifactStore: job outputs on disk at <root>/<kb>/<kind>/<id>.<ext>, written atomically."""

from __future__ import annotations

import contextlib
import io
import json
import os
import tempfile
from pathlib import Path
from typing import Any, Protocol, TypeVar

import numpy as np
from pydantic import BaseModel

M = TypeVar("M", bound=BaseModel)

KINDS = ("raw", "doc_model", "chunks", "entities", "vectors", "source_map")


class ArtifactNotFound(FileNotFoundError):
    pass


class ArtifactStore(Protocol):
    def exists(self, kb: str, kind: str, id: str, ext: str = "json") -> bool: ...
    def write_bytes(self, kb: str, kind: str, id: str, data: bytes, ext: str = "bin") -> None: ...
    def read_bytes(self, kb: str, kind: str, id: str, ext: str = "bin") -> bytes: ...
    def write_model(self, kb: str, kind: str, id: str, model: BaseModel) -> None: ...
    def read_model(self, kb: str, kind: str, id: str, cls: type[M]) -> M: ...
    def write_json(self, kb: str, kind: str, id: str, value: Any) -> None: ...
    def read_json(self, kb: str, kind: str, id: str) -> Any | None: ...
    def write_array(self, kb: str, kind: str, id: str, array: np.ndarray) -> None: ...
    def read_array(self, kb: str, kind: str, id: str) -> np.ndarray: ...


def atomic_write(path: Path, data: bytes) -> None:
    """Write to a temp file in the same folder, then rename over the target."""
    path.parent.mkdir(parents=True, exist_ok=True)
    fd, tmp = tempfile.mkstemp(dir=path.parent, prefix=f".{path.name}.", suffix=".tmp")
    try:
        with os.fdopen(fd, "wb") as fh:
            fh.write(data)
            fh.flush()
            os.fsync(fh.fileno())
        os.replace(tmp, path)
    except BaseException:
        with contextlib.suppress(FileNotFoundError):
            os.unlink(tmp)
        raise


class FileArtifactStore:
    def __init__(self, root: str | Path):
        self.root = Path(root)

    def path(self, kb: str, kind: str, id: str, ext: str) -> Path:
        if kind not in KINDS:
            raise ValueError(f"unknown artifact kind {kind!r}")
        if not id or "/" in id or "\\" in id or id.startswith("."):
            raise ValueError(f"invalid artifact id {id!r}")
        return self.root / kb / kind / f"{id}.{ext}"

    def exists(self, kb: str, kind: str, id: str, ext: str = "json") -> bool:
        return self.path(kb, kind, id, ext).is_file()

    def write_bytes(self, kb: str, kind: str, id: str, data: bytes, ext: str = "bin") -> None:
        atomic_write(self.path(kb, kind, id, ext), data)

    def read_bytes(self, kb: str, kind: str, id: str, ext: str = "bin") -> bytes:
        path = self.path(kb, kind, id, ext)
        try:
            return path.read_bytes()
        except FileNotFoundError:
            raise ArtifactNotFound(str(path)) from None

    def write_model(self, kb: str, kind: str, id: str, model: BaseModel) -> None:
        self.write_bytes(kb, kind, id, model.model_dump_json().encode("utf-8"), ext="json")

    def read_model(self, kb: str, kind: str, id: str, cls: type[M]) -> M:
        return cls.model_validate_json(self.read_bytes(kb, kind, id, ext="json"))

    def write_json(self, kb: str, kind: str, id: str, value: Any) -> None:
        data = json.dumps(value, sort_keys=True, default=str).encode("utf-8")
        self.write_bytes(kb, kind, id, data, ext="json")

    def read_json(self, kb: str, kind: str, id: str) -> Any | None:
        try:
            return json.loads(self.read_bytes(kb, kind, id, ext="json"))
        except ArtifactNotFound:
            return None

    def write_array(self, kb: str, kind: str, id: str, array: np.ndarray) -> None:
        buf = io.BytesIO()
        np.save(buf, array, allow_pickle=False)
        self.write_bytes(kb, kind, id, buf.getvalue(), ext="npy")

    def read_array(self, kb: str, kind: str, id: str) -> np.ndarray:
        return np.load(io.BytesIO(self.read_bytes(kb, kind, id, ext="npy")), allow_pickle=False)
```

"""Connector interface: list documents in a source and fetch their bytes."""

from __future__ import annotations

import mimetypes
from abc import ABC, abstractmethod
from collections.abc import Iterator
from typing import ClassVar

from mayakb.core.contracts import RawDocument, SourceRef

DOCX_MIME = "application/vnd.openxmlformats-officedocument.wordprocessingml.document"

_MIME_BY_SUFFIX = {
    ".pdf": "application/pdf",
    ".docx": DOCX_MIME,
    ".txt": "text/plain",
    ".md": "text/markdown",
    ".markdown": "text/markdown",
}

DEFAULT_SUFFIXES = (".pdf", ".docx", ".txt", ".md")


def guess_mime(name: str) -> str:
    lower = name.lower()
    for suffix, mime in _MIME_BY_SUFFIX.items():
        if lower.endswith(suffix):
            return mime
    return mimetypes.guess_type(name)[0] or "application/octet-stream"


class Connector(ABC):
    name: ClassVar[str]
    version: ClassVar[str] = "1"

    @abstractmethod
    def list(self) -> Iterator[SourceRef]:
        """Every document in the source, with an etag when the source provides one."""

    @abstractmethod
    def fetch(self, ref: SourceRef) -> tuple[RawDocument, bytes]:
        """The document's bytes and its metadata. RawDocument.id must be content_id(bytes)."""
```

"""Files under a folder, e.g. one mounted into the app container at /sources."""

from __future__ import annotations

from collections.abc import Iterator
from datetime import UTC, datetime
from pathlib import Path
from urllib.parse import urlparse
from urllib.request import url2pathname

from mayakb.core.contracts import RawDocument, SourceRef
from mayakb.core.ids import content_id
from mayakb.ingest.connectors.base import DEFAULT_SUFFIXES, Connector, guess_mime


class LocalConnector(Connector):
    name = "local"
    version = "1"

    def __init__(self, path: str, suffixes: list[str] | None = None):
        self.root = Path(path)
        self.suffixes = tuple(s.lower() for s in (suffixes or DEFAULT_SUFFIXES))

    def list(self) -> Iterator[SourceRef]:
        if not self.root.is_dir():
            raise FileNotFoundError(f"source folder not found: {self.root}")
        for path in sorted(self.root.rglob("*")):
            relative = path.relative_to(self.root)
            if any(part.startswith(".") for part in relative.parts):
                continue
            if not path.is_file() or path.suffix.lower() not in self.suffixes:
                continue
            stat = path.stat()
            yield SourceRef(
                uri=path.resolve().as_uri(),
                etag=f"{stat.st_size}-{stat.st_mtime_ns}",
                modified_at=datetime.fromtimestamp(stat.st_mtime, tz=UTC),
                size=stat.st_size,
            )

    def fetch(self, ref: SourceRef) -> tuple[RawDocument, bytes]:
        path = Path(url2pathname(urlparse(ref.uri).path))
        data = path.read_bytes()
        raw = RawDocument(
            id=content_id(data),
            source_uri=ref.uri,
            connector=self.name,
            mime=guess_mime(path.name),
            etag=ref.etag,
            modified_at=ref.modified_at,
            metadata={"size": len(data), "filename": path.name},
        )
        return raw, data

"""Objects in an S3 bucket. Credentials come from the standard AWS chain (IAM role on EC2)."""

from __future__ import annotations

from collections.abc import Iterator
from typing import Any

from mayakb.core.contracts import RawDocument, SourceRef
from mayakb.core.ids import content_id
from mayakb.ingest.connectors.base import DEFAULT_SUFFIXES, Connector, guess_mime


def parse_s3_uri(uri: str) -> tuple[str, str]:
    if not uri.startswith("s3://"):
        raise ValueError(f"not an s3://bucket/key uri: {uri!r}")
    bucket, _, key = uri[len("s3://"):].partition("/")
    if not bucket or not key:
        raise ValueError(f"not an s3://bucket/key uri: {uri!r}")
    return bucket, key


class S3Connector(Connector):
    name = "s3"
    version = "1"

    def __init__(
        self,
        bucket: str,
        prefix: str = "",
        suffixes: list[str] | None = None,
        region: str | None = None,
        endpoint_url: str | None = None,
        client: Any = None,
    ):
        self.bucket = bucket
        self.prefix = prefix
        self.suffixes = tuple(s.lower() for s in (suffixes or DEFAULT_SUFFIXES))
        if client is None:
            import boto3

            client = boto3.client("s3", region_name=region, endpoint_url=endpoint_url)
        self.client = client

    def list(self) -> Iterator[SourceRef]:
        paginator = self.client.get_paginator("list_objects_v2")
        for page in paginator.paginate(Bucket=self.bucket, Prefix=self.prefix):
            for obj in page.get("Contents", []):
                key = obj["Key"]
                if key.endswith("/") or not key.lower().endswith(self.suffixes):
                    continue
                yield SourceRef(
                    uri=f"s3://{self.bucket}/{key}",
                    etag=obj["ETag"].strip('"'),
                    modified_at=obj["LastModified"],
                    size=obj["Size"],
                )

    def fetch(self, ref: SourceRef) -> tuple[RawDocument, bytes]:
        bucket, key = parse_s3_uri(ref.uri)
        data = self.client.get_object(Bucket=bucket, Key=key)["Body"].read()
        raw = RawDocument(
            id=content_id(data),
            source_uri=ref.uri,
            connector=self.name,
            mime=guess_mime(key),
            etag=ref.etag,
            modified_at=ref.modified_at,
            metadata={"size": len(data), "filename": key.rsplit("/", 1)[-1]},
        )
        return raw, data
```

```python
"""Parser interface and helpers shared by every parser."""

from __future__ import annotations

from abc import ABC, abstractmethod
from typing import ClassVar

from mayakb.core.contracts import DocModel, Element, ElementType, RawDocument


class UnsupportedDocument(ValueError):
    """The parser cannot read this kind of file."""


class Parser(ABC):
    name: ClassVar[str]
    version: ClassVar[str] = "1"

    @abstractmethod
    def parse(self, raw: RawDocument, data: bytes) -> DocModel:
        """Turn raw bytes into the common DocModel. doc_id must be raw.id."""


class SectionTracker:
    """The current heading path while walking a document top to bottom."""

    def __init__(self) -> None:
        self._stack: list[tuple[int, str]] = []

    def heading(self, level: int, text: str) -> None:
        while self._stack and self._stack[-1][0] >= level:
            self._stack.pop()
        self._stack.append((level, text))

    @property
    def path(self) -> list[str]:
        return [text for _, text in self._stack]


class ElementBuilder:
    """Collects elements with sequential ids and the section path they belong to."""

    def __init__(self) -> None:
        self.sections = SectionTracker()
        self.elements: list[Element] = []

    def add(
        self,
        type: ElementType,
        text: str,
        *,
        page: int | None = None,
        level: int | None = None,
        bbox: tuple[float, float, float, float] | None = None,
    ) -> None:
        text = text.strip("\n") if type == "code" else text.strip()
        if not text.strip():
            return
        if type == "heading":
            level = level or 1
            self.sections.heading(level, text)
        self.elements.append(
            Element(
                id=f"e{len(self.elements)}",
                type=type,
                text=text,
                page=page,
                section_path=self.sections.path,
                level=level if type == "heading" else None,
                bbox=bbox,
            )
        )


def first_heading(elements: list[Element]) -> str | None:
    return next((e.text for e in elements if e.type == "heading"), None)


def decode_text(data: bytes) -> str:
    return data.decode("utf-8-sig", errors="replace")
```

````python
"""Markdown and plain text -> elements."""

from __future__ import annotations

import re

from mayakb.ingest.parsers.base import ElementBuilder

_HEADING = re.compile(r"^(#{1,6})\s+(.*?)(?:\s+#+)?\s*$")
_LIST_ITEM = re.compile(r"^\s*(?:[-*+]|\d+[.)])\s+")
_FENCE = re.compile(r"^\s*(```|~~~)")


def _line_kind(line: str) -> str:
    if line.lstrip().startswith("|"):
        return "table"
    if _LIST_ITEM.match(line):
        return "list"
    return "paragraph"


def parse_markdown_into(
    builder: ElementBuilder, text: str, *, page: int | None = None, headings: bool = True
) -> None:
    """Add elements for `text`. With headings=False, '#' lines are ordinary text (plain .txt)."""
    lines = text.splitlines()
    block: list[str] = []
    block_kind: str | None = None

    def flush() -> None:
        nonlocal block, block_kind
        if block and block_kind:
            builder.add(block_kind, "\n".join(block), page=page)
        block, block_kind = [], None

    i = 0
    while i < len(lines):
        line = lines[i]
        fence = _FENCE.match(line)
        if fence:
            flush()
            marker = fence.group(1)
            code: list[str] = []
            i += 1
            while i < len(lines) and not lines[i].lstrip().startswith(marker):
                code.append(lines[i])
                i += 1
            builder.add("code", "\n".join(code), page=page)
            i += 1  # closing fence
            continue
        heading = _HEADING.match(line) if headings else None
        if heading:
            flush()
            builder.add("heading", heading.group(2), page=page, level=len(heading.group(1)))
        elif not line.strip():
            flush()
        else:
            kind = _line_kind(line)
            # an indented or wrapped line under a list item stays in the list
            continues_list = block_kind == "list" and kind == "paragraph"
            if block_kind is not None and kind != block_kind and not continues_list:
                flush()
            if block_kind is None:
                block_kind = kind
            block.append(line)
        i += 1
    flush()
````

"""PDF -> elements with PyMuPDF. Headings are detected from font size, tables with find_tables()."""

from __future__ import annotations

from collections import Counter

import pymupdf

from mayakb.ingest.parsers.base import ElementBuilder

if hasattr(pymupdf, "no_recommend_layout"):
    pymupdf.no_recommend_layout()  # otherwise PyMuPDF prints an advert to stdout

HEADING_SIZE_RATIO = 1.15  # a block this much larger than body text is a heading
MAX_HEADING_CHARS = 200


def _overlaps(a: tuple, b: tuple) -> bool:
    return not (a[2] <= b[0] or b[2] <= a[0] or a[3] <= b[1] or b[3] <= a[1])


def _is_heading(text: str, size: float, body_size: float) -> bool:
    return body_size > 0 and size >= body_size * HEADING_SIZE_RATIO and len(text) <= MAX_HEADING_CHARS


def parse_pdf_into(builder: ElementBuilder, data: bytes) -> str | None:
    """Add elements for every page. Returns the PDF's title metadata, if set."""
    pages: list[tuple[int, list[tuple[float, str, object, tuple]]]] = []
    chars_by_size: Counter[float] = Counter()
    with pymupdf.open(stream=data, filetype="pdf") as doc:
        title = (doc.metadata or {}).get("title") or None
        for page_number, page in enumerate(doc, start=1):
            items: list[tuple[float, str, object, tuple]] = []
            table_boxes: list[tuple] = []
            try:
                for table in page.find_tables().tables:
                    box = tuple(table.bbox)
                    table_boxes.append(box)
                    items.append((box[1], "table", table.to_markdown(), box))
            except Exception:  # table detection is best effort; fall back to plain text
                items, table_boxes = [], []
            for block in page.get_text("dict")["blocks"]:
                if block.get("type") != 0:
                    continue
                box = tuple(block["bbox"])
                if any(_overlaps(box, t) for t in table_boxes):
                    continue
                spans = [s for line in block["lines"] for s in line["spans"] if s["text"].strip()]
                if not spans:
                    continue
                text = "\n".join("".join(s["text"] for s in line["spans"]) for line in block["lines"])
                size = round(max(s["size"] for s in spans), 1)
                for span in spans:
                    chars_by_size[round(span["size"], 1)] += len(span["text"])
                items.append((box[1], "text", (text.strip(), size), box))
            items.sort(key=lambda item: item[0])
            pages.append((page_number, items))

    body_size = chars_by_size.most_common(1)[0][0] if chars_by_size else 0.0
    heading_sizes = sorted(
        {
            payload[1]
            for _, items in pages
            for _, kind, payload, _ in items
            if kind == "text" and _is_heading(payload[0], payload[1], body_size)
        },
        reverse=True,
    )
    level_by_size = {size: min(i + 1, 6) for i, size in enumerate(heading_sizes)}

    for page_number, items in pages:
        for _, kind, payload, box in items:
            if kind == "table":
                builder.add("table", payload, page=page_number, bbox=box)
                continue
            text, size = payload
            if _is_heading(text, size, body_size):
                builder.add("heading", " ".join(text.split()), page=page_number, level=level_by_size[size], bbox=box)
            else:
                builder.add("paragraph", text, page=page_number, bbox=box)
    return title
```

"""DOCX -> elements with python-docx. Headings come from paragraph styles."""

from __future__ import annotations

import io
import re

import docx
from docx.table import Table

from mayakb.ingest.parsers.base import ElementBuilder

_HEADING_STYLE = re.compile(r"^Heading (\d)$")


def table_to_markdown(rows: list[list[str]]) -> str:
    rows = [row for row in rows if any(cell.strip() for cell in row)]
    if not rows:
        return ""
    width = max(len(row) for row in rows)
    rows = [row + [""] * (width - len(row)) for row in rows]

    def line(cells: list[str]) -> str:
        return "| " + " | ".join(c.replace("|", "\\|").replace("\n", " ") for c in cells) + " |"

    return "\n".join([line(rows[0]), line(["---"] * width), *(line(row) for row in rows[1:])])


def parse_docx_into(builder: ElementBuilder, data: bytes) -> str | None:
    """Add elements in document order. Returns the core-properties title, if set."""
    document = docx.Document(io.BytesIO(data))
    for item in document.iter_inner_content():
        if isinstance(item, Table):
            rows = [[cell.text.strip() for cell in row.cells] for row in item.rows]
            builder.add("table", table_to_markdown(rows))
            continue
        style = item.style.name if item.style is not None else ""
        heading = _HEADING_STYLE.match(style)
        if style == "Title":
            builder.add("heading", item.text, level=1)
        elif heading:
            builder.add("heading", item.text, level=int(heading.group(1)))
        elif style.startswith("List"):
            builder.add("list", item.text)
        else:
            builder.add("paragraph", item.text)
    return document.core_properties.title or None

from __future__ import annotations

from mayakb.core.contracts import DocModel, RawDocument
from mayakb.ingest.connectors.base import DOCX_MIME
from mayakb.ingest.parsers.base import (
    ElementBuilder,
    Parser,
    UnsupportedDocument,
    decode_text,
    first_heading,
)
from mayakb.ingest.parsers.docx import parse_docx_into
from mayakb.ingest.parsers.markdown import parse_markdown_into
from mayakb.ingest.parsers.pdf import parse_pdf_into


class LocalParser(Parser):
    name = "local"
    version = "1"

    def parse(self, raw: RawDocument, data: bytes) -> DocModel:
        builder = ElementBuilder()
        title: str | None = None
        if raw.mime == "application/pdf":
            title = parse_pdf_into(builder, data)
        elif raw.mime == DOCX_MIME:
            title = parse_docx_into(builder, data)
        elif raw.mime == "text/markdown":
            parse_markdown_into(builder, decode_text(data))
        elif raw.mime.startswith("text/"):
            parse_markdown_into(builder, decode_text(data), headings=False)
        else:
            raise UnsupportedDocument(f"local parser cannot read {raw.mime} ({raw.source_uri})")
        return DocModel(
            doc_id=raw.id,
            parser=self.name,
            source_uri=raw.source_uri,
            title=title or first_heading(builder.elements) or raw.metadata.get("filename"),
            acl=raw.acl,
            metadata={"mime": raw.mime},
            elements=builder.elements,
        )

```python
"""Retry with exponential backoff for calls to network services."""

from __future__ import annotations

import time
from collections.abc import Callable

import httpx


def is_transient(exc: BaseException) -> bool:
    """Connection problems, timeouts, 429 and 5xx are worth retrying; other errors are not."""
    if isinstance(exc, httpx.TransportError):
        return True
    if isinstance(exc, httpx.HTTPStatusError):
        status = exc.response.status_code
        return status == 429 or status >= 500
    return False


def with_retries[T](
    fn: Callable[[], T],
    *,
    attempts: int = 3,
    base_delay: float = 1.0,
    sleep: Callable[[float], None] = time.sleep,
    retryable: Callable[[BaseException], bool] = is_transient,
) -> T:
    for attempt in range(1, attempts + 1):
        try:
            return fn()
        except Exception as exc:
            if attempt == attempts or not retryable(exc):
                raise
            sleep(base_delay * 2 ** (attempt - 1))
    raise AssertionError("unreachable")
```

```python
"""LlamaParse (LlamaCloud) parser. Online: the document is uploaded to LlamaIndex's servers.

API: POST /api/v2/parse/upload, then poll GET /api/v2/parse/{job_id}, then fetch per-page
markdown with ?expand=markdown. Check https://developers.llamaindex.ai/llamaparse/ if it changes.
"""

from __future__ import annotations

import json
import os
import time
from collections.abc import Callable
from typing import Any

import httpx

from mayakb.core.contracts import DocModel, RawDocument
from mayakb.core.retry import with_retries
from mayakb.ingest.parsers.base import ElementBuilder, Parser, first_heading
from mayakb.ingest.parsers.markdown import parse_markdown_into

DEFAULT_BASE_URL = "https://api.cloud.llamaindex.ai"


class LlamaParseError(RuntimeError):
    pass


def extract_pages(payload: dict[str, Any]) -> list[tuple[int, str]]:
    """(1-based page number, markdown) from an ?expand=markdown response.

    Documented shape: {"job": {...}, "markdown": {"pages": [{"page_number": 1, "markdown": "..."}]}}.
    Also accepts {"job": {"markdown": [{"page": 0, "content": "..."}]}} (0-based pages).
    """
    markdown = payload.get("markdown")
    if isinstance(markdown, dict) and isinstance(markdown.get("pages"), list):
        return [(int(p["page_number"]), p.get("markdown") or "") for p in markdown["pages"]]
    job_markdown = (payload.get("job") or {}).get("markdown")
    if isinstance(job_markdown, list):
        return [(int(p["page"]) + 1, p.get("content") or "") for p in job_markdown]
    raise LlamaParseError("LlamaParse response has no per-page markdown")


class LlamaParseParser(Parser):
    name = "llamaparse"
    version = "1"

    def __init__(
        self,
        tier: str = "agentic",
        api_version: str = "latest",
        base_url: str = DEFAULT_BASE_URL,
        api_key: str | None = None,
        poll_interval: float = 2.0,
        timeout: float = 600.0,
        transport: httpx.BaseTransport | None = None,
        sleep: Callable[[float], None] = time.sleep,
        clock: Callable[[], float] = time.monotonic,
    ):
        key = api_key or os.environ.get("LLAMA_CLOUD_API_KEY")
        if not key:
            raise ValueError("LLAMA_CLOUD_API_KEY is not set")
        self.tier = tier
        self.api_version = api_version
        self.poll_interval = poll_interval
        self.timeout = timeout
        self._sleep = sleep
        self._clock = clock
        self._client = httpx.Client(
            base_url=base_url,
            headers={"Authorization": f"Bearer {key}"},
            timeout=60.0,
            transport=transport,
        )

    def _request(self, method: str, url: str, **kwargs: Any) -> dict[str, Any]:
        def call() -> dict[str, Any]:
            response = self._client.request(method, url, **kwargs)
            response.raise_for_status()
            return response.json()

        return with_retries(call, sleep=self._sleep)

    def parse(self, raw: RawDocument, data: bytes) -> DocModel:
        job_id = self._upload(raw, data)
        self._wait_until_complete(job_id)
        result = self._request("GET", f"/api/v2/parse/{job_id}", params={"expand": "markdown"})
        builder = ElementBuilder()
        for page_number, markdown in extract_pages(result):
            parse_markdown_into(builder, markdown, page=page_number)
        return DocModel(
            doc_id=raw.id,
            parser=self.name,
            source_uri=raw.source_uri,
            title=first_heading(builder.elements) or raw.metadata.get("filename"),
            acl=raw.acl,
            metadata={"mime": raw.mime, "llamaparse_job_id": job_id},
            elements=builder.elements,
        )

    def _upload(self, raw: RawDocument, data: bytes) -> str:
        body = self._request(
            "POST",
            "/api/v2/parse/upload",
            files={"file": (raw.metadata.get("filename") or "document", data, raw.mime)},
            data={"configuration": json.dumps({"tier": self.tier, "version": self.api_version})},
        )
        job_id = body.get("id") or (body.get("job") or {}).get("id")
        if not job_id:
            raise LlamaParseError(f"upload response has no job id: {body}")
        return job_id

    def _wait_until_complete(self, job_id: str) -> None:
        deadline = self._clock() + self.timeout
        while True:
            body = self._request("GET", f"/api/v2/parse/{job_id}")
            job = body.get("job") or body
            status = job.get("status")
            if status == "COMPLETED":
                return
            if status in {"FAILED", "CANCELLED"}:
                raise LlamaParseError(f"LlamaParse job {job_id} {status}: {job.get('error_message')}")
            if self._clock() > deadline:
                raise TimeoutError(f"LlamaParse job {job_id} still {status} after {self.timeout}s")
            self._sleep(self.poll_interval)

`mayakb/ingest/chunking/base.py`:

```python
"""ChunkingStrategy interface and helpers for building chunk pieces from elements."""

from __future__ import annotations

from abc import ABC, abstractmethod
from typing import ClassVar

from mayakb.core.contracts import ChunkPiece, DocModel, Element
from mayakb.core.text import windows, word_pieces


class ChunkingStrategy(ABC):
    name: ClassVar[str]
    version: ClassVar[str] = "1"

    @abstractmethod
    def chunk(self, doc: DocModel) -> list[ChunkPiece]:
        """Split a document into pieces, in reading order."""


def check_sizes(max_tokens: int, overlap_tokens: int) -> None:
    if max_tokens <= 0:
        raise ValueError("max_tokens must be positive")
    if not 0 <= overlap_tokens < max_tokens:
        raise ValueError("overlap_tokens must be >= 0 and smaller than max_tokens")


def piece_from(text: str, elements: list[Element], section_path: list[str] | None = None) -> ChunkPiece:
    """A piece covering `elements`; pages span them, section defaults to the first element's."""
    pages = [e.page for e in elements if e.page is not None]
    return ChunkPiece(
        text=text.strip(),
        element_ids=list(dict.fromkeys(e.id for e in elements)),
        page_start=min(pages) if pages else None,
        page_end=max(pages) if pages else None,
        section_path=list(section_path if section_path is not None else elements[0].section_path),
    )


def element_words(elements: list[Element]) -> list[tuple[str, Element]]:
    """Every word with the element it came from; elements are separated by a blank line."""
    out: list[tuple[str, Element]] = []
    for element in elements:
        pieces = word_pieces(element.text)
        if not pieces:
            continue
        pieces[-1] = pieces[-1].rstrip() + "\n\n"
        out.extend((piece, element) for piece in pieces)
    return out


def window_pieces(words: list[tuple[str, Element]], max_tokens: int, overlap_tokens: int) -> list[ChunkPiece]:
    pieces = []
    for start, end in windows(len(words), max_tokens, overlap_tokens):
        span = words[start:end]
        pieces.append(piece_from("".join(word for word, _ in span), [element for _, element in span]))
    return pieces
```

```python
"""Chunks follow sections: split at headings, keep tables whole, split only what is too big."""

from __future__ import annotations

from mayakb.core.contracts import ChunkPiece, DocModel, Element
from mayakb.core.text import count_tokens
from mayakb.ingest.chunking.base import (
    ChunkingStrategy,
    check_sizes,
    element_words,
    piece_from,
    window_pieces,
)


def split_sections(elements: list[Element]) -> list[list[Element]]:
    """A new section starts at a heading that follows content. Consecutive headings stay together."""
    sections: list[list[Element]] = []
    current: list[Element] = []
    for element in elements:
        if element.type == "heading" and any(e.type != "heading" for e in current):
            sections.append(current)
            current = []
        current.append(element)
    if current:
        sections.append(current)
    return sections


class BySectionChunker(ChunkingStrategy):
    name = "by_section"
    version = "1"

    def __init__(self, max_tokens: int = 512, overlap_tokens: int = 50):
        check_sizes(max_tokens, overlap_tokens)
        self.max_tokens = max_tokens
        self.overlap_tokens = overlap_tokens

    def chunk(self, doc: DocModel) -> list[ChunkPiece]:
        pieces: list[ChunkPiece] = []
        for section in split_sections(doc.elements):
            pieces.extend(self._chunk_section(section))
        return pieces

    def _chunk_section(self, elements: list[Element]) -> list[ChunkPiece]:
        section_path = elements[-1].section_path  # the deepest heading path in this section
        pieces: list[ChunkPiece] = []
        batch: list[Element] = []
        batch_tokens = 0

        def flush() -> None:
            nonlocal batch, batch_tokens
            if batch:
                pieces.append(piece_from("\n\n".join(e.text for e in batch), batch, section_path))
            batch, batch_tokens = [], 0

        for element in elements:
            tokens = count_tokens(element.text)
            if tokens > self.max_tokens:
                flush()
                if element.type == "table":
                    pieces.extend(self._split_table(element))
                else:
                    pieces.extend(window_pieces(element_words([element]), self.max_tokens, self.overlap_tokens))
                continue
            if batch_tokens + tokens > self.max_tokens:
                flush()
            batch.append(element)
            batch_tokens += tokens
        flush()
        return pieces

    def _split_table(self, table: Element) -> list[ChunkPiece]:
        """Split a markdown table by rows, repeating the header in every piece."""
        lines = table.text.splitlines()
        is_separator = len(lines) > 1 and set(lines[1].replace("|", "").strip()) <= set("-: ")
        header = lines[:2] if is_separator else lines[:1]
        budget = max(self.max_tokens - count_tokens("\n".join(header)), 1)
        pieces: list[ChunkPiece] = []
        rows: list[str] = []
        used = 0
        for row in lines[len(header):]:
            tokens = count_tokens(row)
            if rows and used + tokens > budget:
                pieces.append(piece_from("\n".join(header + rows), [table]))
                rows, used = [], 0
            rows.append(row)
            used += tokens
        if rows:
            pieces.append(piece_from("\n".join(header + rows), [table]))
        return pieces
```

"""Named entities with spaCy. Needs the `ner` extra and a downloaded model (e.g. en_core_web_sm)."""

from __future__ import annotations

from typing import Any

from mayakb.core.contracts import Chunk, Entity
from mayakb.core.text import normalize_entity
from mayakb.ingest.ner.base import EntityExtractor


class SpacyExtractor(EntityExtractor):
    name = "spacy"
    version = "1"

    def __init__(
        self,
        model: str = "en_core_web_sm",
        labels: list[str] | None = None,
        batch_size: int = 32,
        nlp: Any = None,
    ):
        if nlp is None:
            import spacy

            nlp = spacy.load(model)
        self.nlp = nlp
        self.labels = set(labels) if labels else None
        self.batch_size = batch_size

    def extract(self, chunks: list[Chunk]) -> list[Entity]:
        entities: list[Entity] = []
        docs = self.nlp.pipe((chunk.text for chunk in chunks), batch_size=self.batch_size)
        for chunk, doc in zip(chunks, docs, strict=True):
            for ent in doc.ents:
                if self.labels is not None and ent.label_ not in self.labels:
                    continue
                entities.append(
                    Entity(
                        chunk_id=chunk.chunk_id,
                        text=ent.text,
                        label=ent.label_,
                        normalized=normalize_entity(ent.text),
                        start=ent.start_char,
                        end=ent.end_char,
                    )
                )
        return entities
```

"""Embedder interface."""

from __future__ import annotations

from abc import ABC, abstractmethod
from typing import ClassVar


class EmbeddingError(RuntimeError):
    pass


class Embedder(ABC):
    name: ClassVar[str]
    version: ClassVar[str] = "1"
    model: str

    @abstractmethod
    def embed_documents(self, texts: list[str]) -> list[list[float]]:
        """One vector per text, for indexing."""

    @abstractmethod
    def embed_query(self, text: str) -> list[float]:

"""Embeddings from an Ollama server (POST /api/embed)."""

from __future__ import annotations

import time
from collections.abc import Callable
from typing import Any

import httpx

from mayakb.core.config import Settings
from mayakb.core.retry import with_retries
from mayakb.ingest.embedders.base import Embedder, EmbeddingError

# Models trained with task prefixes: (document prefix, query prefix)
PREFIXES = {
    "nomic-embed-text": ("search_document: ", "search_query: "),
}


def _base_model(model: str) -> str:
    return model.split(":", 1)[0].rsplit("/", 1)[-1]


class OllamaEmbedder(Embedder):
    name = "ollama"
    version = "1"

    def __init__(
        self,
        model: str = "nomic-embed-text",
        base_url: str | None = None,
        batch_size: int = 32,
        timeout: float = 120.0,
        document_prefix: str | None = None,
        query_prefix: str | None = None,
        transport: httpx.BaseTransport | None = None,
        sleep: Callable[[float], None] = time.sleep,
    ):
        default_document, default_query = PREFIXES.get(_base_model(model), ("", ""))
        self.model = model
        self.batch_size = batch_size
        self.document_prefix = default_document if document_prefix is None else document_prefix
        self.query_prefix = default_query if query_prefix is None else query_prefix
        self._sleep = sleep
        self._client = httpx.Client(
            base_url=base_url or Settings.from_env().ollama_url, timeout=timeout, transport=transport
        )

    def embed_documents(self, texts: list[str]) -> list[list[float]]:
        return self._embed([self.document_prefix + text for text in texts])

    def embed_query(self, text: str) -> list[float]:
        return self._embed([self.query_prefix + text])[0]

    def _post(self, batch: list[str]) -> dict[str, Any]:
        response = self._client.post("/api/embed", json={"model": self.model, "input": batch})
        if response.status_code == 404:
            raise EmbeddingError(f"Ollama has no model {self.model!r}; run `ollama pull {self.model}`")
        response.raise_for_status()
        return response.json()

    def _embed(self, inputs: list[str]) -> list[list[float]]:
        vectors: list[list[float]] = []
        for start in range(0, len(inputs), self.batch_size):
            batch = inputs[start:start + self.batch_size]
            body = with_retries(lambda batch=batch: self._post(batch), sleep=self._sleep)
            embeddings = body.get("embeddings") or []
            if len(embeddings) != len(batch):
                raise EmbeddingError(
                    f"Ollama returned {len(embeddings)} embeddings for {len(batch)} inputs (model {self.model})"
                )
            vectors.extend(embeddings)
        return vectors
```

```python
"""Postgres connection pool and schema migrations."""

from __future__ import annotations

import re
from pathlib import Path

import psycopg
from pgvector.psycopg import register_vector
from psycopg_pool import ConnectionPool, PoolTimeout

MIGRATIONS_DIR = Path(__file__).parent / "migrations"
MIN_PGVECTOR = (0, 8, 0)  # iterative index scans keep filtered vector searches from coming back short
_MIGRATION_LOCK = 7_272_727  # advisory lock key: two containers never migrate at the same time


class DatabaseUnavailable(RuntimeError):
    pass


def redact(url: str) -> str:
    """Hide the password in a connection URL."""
    return re.sub(r"(://[^:/@]+:)[^@]*@", r"\1***@", url)


def apply_migrations(database_url: str) -> list[str]:
    """Apply migrations/*.sql not yet recorded in schema_migrations. Returns the ones applied now."""
    try:
        conn = psycopg.connect(database_url, autocommit=True, connect_timeout=10)
    except psycopg.OperationalError as exc:
        raise DatabaseUnavailable(
            f"cannot connect to Postgres at MAYAKB_DATABASE_URL={redact(database_url)}: {exc}"
        ) from exc
    applied: list[str] = []
    with conn:
        conn.execute("SELECT pg_advisory_lock(%s)", (_MIGRATION_LOCK,))
        try:
            conn.execute(
                "CREATE TABLE IF NOT EXISTS schema_migrations ("
                " version text PRIMARY KEY, applied_at timestamptz NOT NULL DEFAULT now())"
            )
            done = {row[0] for row in conn.execute("SELECT version FROM schema_migrations")}
            for path in sorted(MIGRATIONS_DIR.glob("*.sql")):
                if path.stem in done:
                    continue
                with conn.transaction():
                    conn.execute(path.read_text(encoding="utf-8"))
                    conn.execute("INSERT INTO schema_migrations (version) VALUES (%s)", (path.stem,))
                applied.append(path.stem)
        finally:
            conn.execute("SELECT pg_advisory_unlock(%s)", (_MIGRATION_LOCK,))
    return applied


def pgvector_version(conn: psycopg.Connection) -> tuple[int, ...] | None:
    row = conn.execute("SELECT extversion FROM pg_extension WHERE extname = 'vector'").fetchone()
    if row is None:
        return None
    return tuple(int(part) for part in re.findall(r"\d+", row[0])[:3])


def _configure(conn: psycopg.Connection) -> None:
    register_vector(conn)
    conn.commit()


def make_pool(database_url: str, *, min_size: int = 1, max_size: int = 10, timeout: float = 10.0) -> ConnectionPool:
    pool = ConnectionPool(database_url, min_size=min_size, max_size=max_size, configure=_configure, open=False)
    try:
        pool.open(wait=True, timeout=timeout)
    except PoolTimeout as exc:
        pool.close()
        raise DatabaseUnavailable(
            f"cannot connect to Postgres at MAYAKB_DATABASE_URL={redact(database_url)} "
            "(is the db container healthy, and has `mayakb db init` run?)"
        ) from exc
    return pool
```

```python
"""Job log: one row per job, updated as the job runs, fails, or is skipped."""

from __future__ import annotations

import threading
from datetime import UTC, datetime
from typing import Literal, Protocol

from psycopg.rows import dict_row
from psycopg_pool import ConnectionPool
from pydantic import BaseModel

JobStatus = Literal["pending", "running", "succeeded", "failed", "skipped"]


class JobRecord(BaseModel):
    job_id: str
    kb: str
    stage: str
    input_ids: list[str]
    output_id: str | None = None
    implementation: str
    params_hash: str
    status: JobStatus
    attempts: int = 0
    error: str | None = None
    started_at: datetime | None = None
    finished_at: datetime | None = None


class JobLog(Protocol):
    def start(
        self, *, job_id: str, kb: str, stage: str, input_ids: list[str], implementation: str, params_hash: str
    ) -> None: ...
    def finish(self, job_id: str, *, status: Literal["succeeded", "skipped"], output_id: str) -> None: ...
    def fail(self, job_id: str, error: str) -> None: ...
    def get(self, job_id: str) -> JobRecord | None: ...
    def list(self, kb: str, status: JobStatus | None = None, limit: int = 100) -> list[JobRecord]: ...


def _now() -> datetime:
    return datetime.now(UTC)


class InMemoryJobLog:
    """For tests and single-process experiments."""

    def __init__(self) -> None:
        self._jobs: dict[str, JobRecord] = {}
        self._lock = threading.Lock()

    def start(self, *, job_id, kb, stage, input_ids, implementation, params_hash) -> None:
        with self._lock:
            previous = self._jobs.get(job_id)
            self._jobs[job_id] = JobRecord(
                job_id=job_id,
                kb=kb,
                stage=stage,
                input_ids=list(input_ids),
                output_id=previous.output_id if previous else None,
                implementation=implementation,
                params_hash=params_hash,
                status="running",
                attempts=(previous.attempts if previous else 0) + 1,
                started_at=_now(),
            )

    def finish(self, job_id, *, status, output_id) -> None:
        with self._lock:
            record = self._jobs[job_id]
            self._jobs[job_id] = record.model_copy(
                update={"status": status, "output_id": output_id, "error": None, "finished_at": _now()}
            )

    def fail(self, job_id, error) -> None:
        with self._lock:
            record = self._jobs[job_id]
            self._jobs[job_id] = record.model_copy(update={"status": "failed", "error": error, "finished_at": _now()})

    def get(self, job_id) -> JobRecord | None:
        with self._lock:
            record = self._jobs.get(job_id)
            return record.model_copy() if record else None

    def list(self, kb, status=None, limit=100) -> list[JobRecord]:
        with self._lock:
            records = [r for r in self._jobs.values() if r.kb == kb and (status is None or r.status == status)]
        records.sort(key=lambda r: r.started_at or datetime.min.replace(tzinfo=UTC), reverse=True)
        return records[:limit]


_COLUMNS = (
    "job_id, kb, stage, input_ids, output_id, implementation, params_hash, "
    "status, attempts, error, started_at, finished_at"
)


class PostgresJobLog:
    def __init__(self, pool: ConnectionPool):
        self.pool = pool

    def start(self, *, job_id, kb, stage, input_ids, implementation, params_hash) -> None:
        with self.pool.connection() as conn:
            conn.execute(
                """
                INSERT INTO jobs (job_id, kb, stage, input_ids, implementation, params_hash,
                                  status, attempts, started_at)
                VALUES (%s, %s, %s, %s, %s, %s, 'running', 1, now())
                ON CONFLICT (job_id) DO UPDATE SET
                    status = 'running', attempts = jobs.attempts + 1, error = NULL,
                    implementation = EXCLUDED.implementation, params_hash = EXCLUDED.params_hash,
                    started_at = now(), finished_at = NULL
                """,
                (job_id, kb, stage, list(input_ids), implementation, params_hash),
            )

    def finish(self, job_id, *, status, output_id) -> None:
        with self.pool.connection() as conn:
            conn.execute(
                "UPDATE jobs SET status = %s, output_id = %s, error = NULL, finished_at = now() WHERE job_id = %s",
                (status, output_id, job_id),
            )

    def fail(self, job_id, error) -> None:
        with self.pool.connection() as conn:
            conn.execute(
                "UPDATE jobs SET status = 'failed', error = %s, finished_at = now() WHERE job_id = %s",
                (error, job_id),
            )

    def get(self, job_id) -> JobRecord | None:
        with self.pool.connection() as conn:
            row = conn.cursor(row_factory=dict_row).execute(
                f"SELECT {_COLUMNS} FROM jobs WHERE job_id = %s", (job_id,)
            ).fetchone()
        return JobRecord(**row) if row else None

    def list(self, kb, status=None, limit=100) -> list[JobRecord]:
        query = f"SELECT {_COLUMNS} FROM jobs WHERE kb = %s"
        params: list[object] = [kb]
        if status is not None:
            query += " AND status = %s"
            params.append(status)
        query += " ORDER BY started_at DESC NULLS LAST LIMIT %s"
        params.append(limit)
        with self.pool.connection() as conn:
            rows = conn.cursor(row_factory=dict_row).execute(query, params).fetchall()
        return [JobRecord(**row) for row in rows]
```

"""SearchBackend interface: stores index rows and runs dense and keyword searches with filters inside."""

from __future__ import annotations

import re
from typing import Any, ClassVar, Protocol

from pydantic import BaseModel, Field

from mayakb.core.ids import stable_id
from mayakb.core.text import normalize_entity


class Filters(BaseModel):
    source_prefix: str | None = None
    entities: list[str] | None = None
    principals: list[str] | None = None  # reserved ACL filter; None means no ACL filtering

    def normalized(self) -> Filters:
        if not self.entities:
            return self
        return self.model_copy(update={"entities": [normalize_entity(e) for e in self.entities]})


class IndexInfo(BaseModel):
    index_id: str
    kb: str
    embedder: str
    model: str
    dim: int
    table_name: str
    text_search_language: str = "english"


class IndexRow(BaseModel):
    chunk_id: str
    doc_id: str
    position: int
    text: str
    embedding: list[float]
    source_uri: str
    title: str | None = None
    page_start: int | None = None
    page_end: int | None = None
    section_path: list[str] = Field(default_factory=list)
    entities: list[str] = Field(default_factory=list)  # normalized entity text
    acl: list[str] | None = None
    metadata: dict[str, Any] = Field(default_factory=dict)


class Hit(BaseModel):
    chunk_id: str
    doc_id: str
    position: int
    text: str
    score: float
    source_uri: str
    title: str | None = None
    page_start: int | None = None
    page_end: int | None = None
    section_path: list[str] = Field(default_factory=list)
    metadata: dict[str, Any] = Field(default_factory=dict)


class SearchBackend(Protocol):
    name: ClassVar[str]
    version: ClassVar[str]

    def ensure_index(
        self, kb: str, embedder: str, model: str, dim: int, text_search_language: str = "english"
    ) -> IndexInfo: ...
    def find_index(self, kb: str, embedder: str, model: str) -> IndexInfo | None: ...
    def list_indexes(self, kb: str) -> list[IndexInfo]: ...
    def upsert(self, rows: list[IndexRow], index: IndexInfo) -> None:
        """Replace each document's rows. For every doc_id in `rows`, rows not in `rows` are deleted;
        rows with the same source_uri but a different doc_id (an older version of the file) too."""
    def dense_search(self, vector: list[float], k: int, filters: Filters, index: IndexInfo) -> list[Hit]:
        """Top k by cosine similarity (score = 1 - cosine distance)."""
    def keyword_search(self, text: str, k: int, filters: Filters, index: IndexInfo) -> list[Hit]:
        """Top k chunks matching the query terms. Chunks with no match are not returned."""


def index_id_for(kb: str, embedder: str, model: str, dim: int) -> str:
    return stable_id("index", kb, embedder, model, dim)


def index_table_name(kb: str, embedder: str, model: str, dim: int) -> str:
    slug = re.sub(r"[^a-z0-9_]", "_", kb.lower())[:30]
    return f"idx_{slug}_{stable_id(embedder, model, dim, length=12)}"

"""In-memory SearchBackend for tests. Same filter and replace rules as Postgres; no stemming."""

from __future__ import annotations

import threading
from collections.abc import Iterator

import numpy as np

from mayakb.core.text import words
from mayakb.storage.search.base import Filters, Hit, IndexInfo, IndexRow, index_id_for, index_table_name


def _hit(row: IndexRow, score: float) -> Hit:
    return Hit(score=score, **row.model_dump(exclude={"embedding", "entities", "acl"}))


class InMemorySearchBackend:
    name = "memory"
    version = "1"

    def __init__(self) -> None:
        self._indexes: dict[str, IndexInfo] = {}
        self._rows: dict[str, dict[str, IndexRow]] = {}
        self._lock = threading.Lock()

    def ensure_index(self, kb, embedder, model, dim, text_search_language="english") -> IndexInfo:
        info = IndexInfo(
            index_id=index_id_for(kb, embedder, model, dim),
            kb=kb,
            embedder=embedder,
            model=model,
            dim=dim,
            table_name=index_table_name(kb, embedder, model, dim),
            text_search_language=text_search_language,
        )
        with self._lock:
            self._rows.setdefault(info.index_id, {})
            return self._indexes.setdefault(info.index_id, info)

    def find_index(self, kb, embedder, model) -> IndexInfo | None:
        matches = [i for i in self._indexes.values() if (i.kb, i.embedder, i.model) == (kb, embedder, model)]
        return matches[-1] if matches else None

    def list_indexes(self, kb) -> list[IndexInfo]:
        return [i for i in self._indexes.values() if i.kb == kb]

    def upsert(self, rows: list[IndexRow], index: IndexInfo) -> None:
        doc_ids = {r.doc_id for r in rows}
        uris = {r.source_uri for r in rows}
        keep = {r.chunk_id for r in rows}
        with self._lock:
            table = self._rows[index.index_id]
            for chunk_id, row in list(table.items()):
                stale_chunk = row.doc_id in doc_ids and chunk_id not in keep
                old_version = row.source_uri in uris and row.doc_id not in doc_ids
                if stale_chunk or old_version:
                    del table[chunk_id]
            for row in rows:
                table[row.chunk_id] = row

    def _filtered(self, filters: Filters, index: IndexInfo) -> Iterator[IndexRow]:
        with self._lock:
            rows = list(self._rows.get(index.index_id, {}).values())
        for row in rows:
            if filters.source_prefix and not row.source_uri.startswith(filters.source_prefix):
                continue
            if filters.entities and not set(filters.entities) & set(row.entities):
                continue
            if filters.principals is not None and row.acl is not None and not set(row.acl) & set(filters.principals):
                continue
            yield row

    def dense_search(self, vector, k, filters, index) -> list[Hit]:
        query = np.asarray(vector, dtype=float)
        query_norm = np.linalg.norm(query)
        scored = []
        for row in self._filtered(filters, index):
            emb = np.asarray(row.embedding, dtype=float)
            denom = query_norm * np.linalg.norm(emb)
            scored.append((float(query @ emb / denom) if denom else 0.0, row))
        scored.sort(key=lambda item: (-item[0], item[1].chunk_id))
        return [_hit(row, score) for score, row in scored[:k]]

    def keyword_search(self, text, k, filters, index) -> list[Hit]:
        terms = set(words(text))
        scored = []
        for row in self._filtered(filters, index):
            row_words = words(row.text)
            score = sum(row_words.count(term) for term in terms) / (len(row_words) or 1)
            if score > 0:
                scored.append((score, row))
        scored.sort(key=lambda item: (-item[0], item[1].chunk_id))
        return [_hit(row, score) for score, row in scored[:k]]
```

"""Postgres SearchBackend: pgvector HNSW for dense search, full-text search for keywords."""

from __future__ import annotations

import re
import warnings

import numpy as np
from psycopg import sql
from psycopg.rows import dict_row
from psycopg.types.json import Jsonb
from psycopg_pool import ConnectionPool

from mayakb.storage.db import MIN_PGVECTOR, DatabaseUnavailable, pgvector_version
from mayakb.storage.search.base import Filters, Hit, IndexInfo, IndexRow, index_id_for, index_table_name

MAX_HNSW_DIM = 2000  # pgvector's HNSW limit for the vector type
_HIT_COLUMNS = (
    "chunk_id", "doc_id", "position", "text", "source_uri", "title",
    "page_start", "page_end", "section_path", "metadata",
)
_INDEX_COLUMNS = "index_id, kb, embedder, model, dim, table_name, text_search_language"


def _columns() -> sql.Composable:
    return sql.SQL(", ").join(sql.Identifier(c) for c in _HIT_COLUMNS)


def _like_prefix(prefix: str) -> str:
    escaped = prefix.replace("\\", "\\\\").replace("%", "\\%").replace("_", "\\_")
    return escaped + "%"


def _where(filters: Filters) -> tuple[sql.Composable, list[object]]:
    clauses: list[sql.Composable] = [sql.SQL("TRUE")]
    params: list[object] = []
    if filters.source_prefix:
        clauses.append(sql.SQL("source_uri LIKE %s"))
        params.append(_like_prefix(filters.source_prefix))
    if filters.entities:
        clauses.append(sql.SQL("entities && %s::text[]"))
        params.append(list(filters.entities))
    if filters.principals is not None:
        clauses.append(sql.SQL("(acl IS NULL OR acl && %s::text[])"))
        params.append(list(filters.principals))
    return sql.SQL(" AND ").join(clauses), params


class PostgresSearchBackend:
    name = "postgres"
    version = "1"

    def __init__(self, pool: ConnectionPool):
        self.pool = pool
        with pool.connection() as conn:
            found = pgvector_version(conn)
        if found is None:
            raise DatabaseUnavailable("the pgvector extension is missing; run `mayakb db init`")
        self.iterative_scan = found >= MIN_PGVECTOR
        if not self.iterative_scan:
            warnings.warn(
                f"pgvector {'.'.join(map(str, found))} is older than 0.8: filtered vector searches "
                "may return fewer hits than requested",
                stacklevel=2,
            )

    # -- index management ---------------------------------------------------------------------

    def _index_rows(self, where: str, params: tuple) -> list[IndexInfo]:
        with self.pool.connection() as conn:
            rows = conn.cursor(row_factory=dict_row).execute(
                f"SELECT {_INDEX_COLUMNS} FROM indexes WHERE {where} ORDER BY created_at", params
            ).fetchall()
        return [IndexInfo(**row) for row in rows]

    def find_index(self, kb, embedder, model) -> IndexInfo | None:
        rows = self._index_rows("kb = %s AND embedder = %s AND model = %s", (kb, embedder, model))
        return rows[-1] if rows else None

    def list_indexes(self, kb) -> list[IndexInfo]:
        return self._index_rows("kb = %s", (kb,))

    def ensure_index(self, kb, embedder, model, dim, text_search_language="english") -> IndexInfo:
        if not 0 < dim <= MAX_HNSW_DIM:
            raise ValueError(f"embedding dimension {dim} is outside 1..{MAX_HNSW_DIM}")
        if not re.fullmatch(r"[a-z_]+", text_search_language):
            raise ValueError(f"invalid text search language {text_search_language!r}")
        index_id = index_id_for(kb, embedder, model, dim)
        table = index_table_name(kb, embedder, model, dim)
        t = sql.Identifier(table)
        with self.pool.connection() as conn, conn.transaction():
            conn.execute("SELECT pg_advisory_xact_lock(hashtext(%s))", (table,))
            conn.execute(
                sql.SQL(
                    """
                    CREATE TABLE IF NOT EXISTS {t} (
                        chunk_id     text PRIMARY KEY,
                        doc_id       text NOT NULL,
                        position     integer NOT NULL,
                        text         text NOT NULL,
                        embedding    vector({dim}) NOT NULL,
                        tsv          tsvector GENERATED ALWAYS AS (to_tsvector({lang}, text)) STORED,
                        source_uri   text NOT NULL,
                        title        text,
                        page_start   integer,
                        page_end     integer,
                        section_path text[] NOT NULL DEFAULT '{{}}',
                        entities     text[] NOT NULL DEFAULT '{{}}',
                        acl          text[],
                        metadata     jsonb NOT NULL DEFAULT '{{}}'
                    )
                    """
                ).format(t=t, dim=sql.Literal(dim), lang=sql.Literal(text_search_language))
            )
            for suffix, method, expression in (
                ("hnsw", "hnsw", "embedding vector_cosine_ops"),
                ("tsv", "gin", "tsv"),
                ("entities", "gin", "entities"),
                ("acl", "gin", "acl"),
                ("doc", "btree", "doc_id"),
                ("uri", "btree", "source_uri"),
            ):
                conn.execute(
                    sql.SQL("CREATE INDEX IF NOT EXISTS {name} ON {t} USING {method} ({expression})").format(
                        name=sql.Identifier(f"{table}_{suffix}"),
                        t=t,
                        method=sql.SQL(method),
                        expression=sql.SQL(expression),
                    )
                )
            conn.execute(
                f"INSERT INTO indexes ({_INDEX_COLUMNS}) VALUES (%s, %s, %s, %s, %s, %s, %s) "
                "ON CONFLICT (index_id) DO NOTHING",
                (index_id, kb, embedder, model, dim, table, text_search_language),
            )
        return self._index_rows("index_id = %s", (index_id,))[0]

    # -- writes -------------------------------------------------------------------------------

    def upsert(self, rows: list[IndexRow], index: IndexInfo) -> None:
        if not rows:
            return
        t = sql.Identifier(index.table_name)
        doc_ids = sorted({r.doc_id for r in rows})
        uris = sorted({r.source_uri for r in rows})
        chunk_ids = [r.chunk_id for r in rows]
        insert = sql.SQL(
            """
            INSERT INTO {t} (chunk_id, doc_id, position, text, embedding, source_uri, title,
                             page_start, page_end, section_path, entities, acl, metadata)
            VALUES (%s, %s, %s, %s, %s, %s, %s, %s, %s, %s, %s, %s, %s)
            ON CONFLICT (chunk_id) DO UPDATE SET
                doc_id = EXCLUDED.doc_id, position = EXCLUDED.position, text = EXCLUDED.text,
                embedding = EXCLUDED.embedding, source_uri = EXCLUDED.source_uri, title = EXCLUDED.title,
                page_start = EXCLUDED.page_start, page_end = EXCLUDED.page_end,
                section_path = EXCLUDED.section_path, entities = EXCLUDED.entities,
                acl = EXCLUDED.acl, metadata = EXCLUDED.metadata
            """
        ).format(t=t)
        values = [
            (
                r.chunk_id, r.doc_id, r.position, r.text, np.asarray(r.embedding, dtype=np.float32),
                r.source_uri, r.title, r.page_start, r.page_end, list(r.section_path), list(r.entities),
                r.acl, Jsonb(r.metadata),
            )
            for r in rows
        ]
        with self.pool.connection() as conn, conn.transaction():
            conn.execute(
                sql.SQL(
                    "DELETE FROM {t} WHERE (doc_id = ANY(%s) AND NOT chunk_id = ANY(%s))"
                    " OR (source_uri = ANY(%s) AND NOT doc_id = ANY(%s))"
                ).format(t=t),
                (doc_ids, chunk_ids, uris, doc_ids),
            )
            with conn.cursor() as cur:
                cur.executemany(insert, values)

    # -- searches -----------------------------------------------------------------------------

    def dense_search(self, vector, k, filters, index) -> list[Hit]:
        where, params = _where(filters)
        query = sql.SQL(
            "SELECT {columns}, 1 - (embedding <=> %s) AS score FROM {t} WHERE {where} "
            "ORDER BY embedding <=> %s LIMIT %s"
        ).format(columns=_columns(), t=sql.Identifier(index.table_name), where=where)
        embedding = np.asarray(vector, dtype=np.float32)
        with self.pool.connection() as conn, conn.transaction():
            conn.execute(sql.SQL("SET LOCAL hnsw.ef_search = {}").format(sql.Literal(min(max(k, 40), 1000))))
            if self.iterative_scan:
                conn.execute("SET LOCAL hnsw.iterative_scan = strict_order")
            rows = conn.cursor(row_factory=dict_row).execute(query, [embedding, *params, embedding, k]).fetchall()
        return [Hit(**row) for row in rows]

    def keyword_search(self, text, k, filters, index) -> list[Hit]:
        where, params = _where(filters)
        query = sql.SQL(
            "SELECT {columns}, ts_rank_cd(tsv, q) AS score "
            "FROM {t}, websearch_to_tsquery({lang}::regconfig, %s) AS q "
            "WHERE tsv @@ q AND {where} ORDER BY score DESC, chunk_id LIMIT %s"
        ).format(
            columns=_columns(),
            t=sql.Identifier(index.table_name),
            lang=sql.Literal(index.text_search_language),
            where=where,
        )
        with self.pool.connection() as conn:
            rows = conn.cursor(row_factory=dict_row).execute(query, [text, *params, k]).fetchall()
        return [Hit(**row) for row in rows]

    version = "1"

        if "bad" in raw.source_uri:
            raise ValueError("cannot parse this one")
        return LocalParser().parse(raw, data)


@register("ner", "capitalized")

    version = "1"

    def extract(self, chunks: list[Chunk]) -> list[Entity]:
        return [
            Entity(chunk_id=c.chunk_id, text=m.group(0), label="WORD", normalized=normalize_entity(m.group(0)),
                   start=m.start(), end=m.end())
            for c in chunks
            for m in re.finditer(r"\b[A-Z][a-z]+\b", c.text)
        ]


@register("embedder", "hash")
class HashEmbedder(Embedder):
    """Bag of hashed words: texts sharing words get similar vectors. Deterministic, no model."""

    version = "1"

    def __init__(self, dim: int = 64, model: str = "hash-64"):
        self.dim = dim
        self.model = model

    def _vector(self, text: str) -> list[float]:
        vector = np.zeros(self.dim)
        for word in words(text):
            vector[int(hashlib.md5(word.encode()).hexdigest(), 16) % self.dim] += 1.0
        norm = np.linalg.norm(vector)
        return (vector / norm if norm else vector).tolist()

    def embed_documents(self, texts):
        return [self._vector(t) for t in texts]

    def embed_query(self, text):
        return self._vector(text)

        "ner": {"extractor": "capitalized"},
        "embed": {"embedder": "hash", "dim": 64},
        "index": {"backend": "memory"},
    }
    data.update(sections)
    return KBConfig.model_validate(data)

```python
"""The six ingestion jobs. Each reads its inputs from the ArtifactStore and writes its output there.

A job is skipped when its output already exists for the same inputs, implementation and params.
"""

from __future__ import annotations

from collections import defaultdict
from collections.abc import Callable
from dataclasses import dataclass
from typing import Literal

import numpy as np
from pydantic import BaseModel

from mayakb.core import registry
from mayakb.core.config import ImplConfig, KBConfig
from mayakb.core.contracts import Chunk, ChunkSet, DocModel, EntitySet, RawDocument, SourceRef, VectorSet
from mayakb.core.ids import stable_id
from mayakb.storage.artifacts import ArtifactStore
from mayakb.storage.joblog import JobLog, JobRecord
from mayakb.storage.search.base import IndexRow, SearchBackend

STAGES = (
    "read_source",
    "understand_document",
    "chunk_document",
    "extract_entities",
    "embed_chunks",
    "index_chunks",
)


@dataclass
class IngestContext:
    kb: KBConfig
    store: ArtifactStore
    joblog: JobLog
    backend: SearchBackend | None = None


class JobResult(BaseModel):
    job_id: str
    stage: str
    status: Literal["succeeded", "skipped"]
    output_id: str


class JobFailed(RuntimeError):
    def __init__(self, job_id: str, stage: str, cause: BaseException):
        super().__init__(f"{stage} failed (job {job_id}): {type(cause).__name__}: {cause}")
        self.job_id = job_id
        self.stage = stage
        self.cause = cause


def _run(
    ctx: IngestContext,
    *,
    stage: str,
    input_ids: list[str],
    impl: ImplConfig,
    version: str,
    check: Callable[[JobRecord | None], str | None],
    work: Callable[[], str],
) -> JobResult:
    """Log the job, skip it if `check` finds its output, otherwise run `work` (returns the output id)."""
    kb = ctx.kb.kb
    job_id = stable_id("job", kb, stage, input_ids, impl.name, version, impl.params)
    previous = ctx.joblog.get(job_id)
    ctx.joblog.start(
        job_id=job_id,
        kb=kb,
        stage=stage,
        input_ids=input_ids,
        implementation=f"{impl.name}@{version}",
        params_hash=stable_id(impl.params),
    )
    try:
        existing = check(previous)
        if existing is not None:
            ctx.joblog.finish(job_id, status="skipped", output_id=existing)
            return JobResult(job_id=job_id, stage=stage, status="skipped", output_id=existing)
        output_id = work()
    except Exception as exc:
        ctx.joblog.fail(job_id, f"{type(exc).__name__}: {exc}")
        raise JobFailed(job_id, stage, exc) from exc
    ctx.joblog.finish(job_id, status="succeeded", output_id=output_id)
    return JobResult(job_id=job_id, stage=stage, status="succeeded", output_id=output_id)


def _artifact_job(
    ctx: IngestContext,
    *,
    stage: str,
    input_ids: list[str],
    kind: str,
    impl: ImplConfig,
    registry_kind: str,
    produce: Callable[[str], None],
) -> JobResult:
    """A job whose output is one artifact with a deterministic id."""
    version = registry.get(registry_kind, impl.name).version
    output_id = stable_id(stage, input_ids, impl.name, version, impl.params)

    def work() -> str:
        produce(output_id)
        return output_id

    return _run(
        ctx,
        stage=stage,
        input_ids=input_ids,
        impl=impl,
        version=version,
        check=lambda _: output_id if ctx.store.exists(ctx.kb.kb, kind, output_id) else None,
        work=work,
    )


def read_source(ref: SourceRef, *, ctx: IngestContext) -> JobResult:
    """Fetch a document. Skipped when the source's etag hasn't changed since the last fetch."""
    impl, kb = ctx.kb.source, ctx.kb.kb
    version = registry.get("connector", impl.name).version
    map_key = stable_id("source", ref.uri)

    def check(_: JobRecord | None) -> str | None:
        seen = ctx.store.read_json(kb, "source_map", map_key)
        unchanged = seen and ref.etag and seen.get("etag") == ref.etag
        return seen["raw_id"] if unchanged and ctx.store.exists(kb, "raw", seen["raw_id"]) else None

    def work() -> str:
        connector = registry.create("connector", impl.name, **impl.params)
        raw, data = connector.fetch(ref)
        ctx.store.write_bytes(kb, "raw", raw.id, data)
        ctx.store.write_model(kb, "raw", raw.id, raw)  # written last: its presence means "complete"
        ctx.store.write_json(kb, "source_map", map_key, {"uri": ref.uri, "etag": ref.etag, "raw_id": raw.id})
        return raw.id

    return _run(ctx, stage="read_source", input_ids=[ref.uri], impl=impl, version=version, check=check, work=work)


def understand_document(raw_id: str, *, ctx: IngestContext) -> JobResult:
    impl, kb = ctx.kb.parse, ctx.kb.kb

    def produce(output_id: str) -> None:
        raw = ctx.store.read_model(kb, "raw", raw_id, RawDocument)
        data = ctx.store.read_bytes(kb, "raw", raw_id)
        parser = registry.create("parser", impl.name, **impl.params)
        ctx.store.write_model(kb, "doc_model", output_id, parser.parse(raw, data))

    return _artifact_job(ctx, stage="understand_document", input_ids=[raw_id], kind="doc_model", impl=impl,
                         registry_kind="parser", produce=produce)


def chunk_document(doc_model_id: str, *, ctx: IngestContext) -> JobResult:

                  position=position, acl=doc.acl)
            for position, piece in enumerate(chunker.chunk(doc))
        ]
        chunk_set = ChunkSet(id=output_id, doc_id=doc.doc_id, source_uri=doc.source_uri, title=doc.title,
                             strategy=impl.name, chunks=chunks)
        ctx.store.write_model(kb, "chunks", output_id, chunk_set)

def embed_chunks(chunk_set_id: str, *, ctx: IngestContext) -> JobResult:
    impl, kb = ctx.kb.embed, ctx.kb.kb

    def produce(output_id: str) -> None:
        chunk_set = ctx.store.read_model(kb, "chunks", chunk_set_id, ChunkSet)
        embedder = registry.create("embedder", impl.name, **impl.params)
        texts = [c.text for c in chunk_set.chunks]
        vectors = np.asarray(embedder.embed_documents(texts) if texts else [], dtype=np.float32)
        dim = int(vectors.shape[1]) if vectors.ndim == 2 else 0
        ctx.store.write_array(kb, "vectors", output_id, vectors)
        ctx.store.write_model(kb, "vectors", output_id, VectorSet(
            id=output_id, chunk_set_id=chunk_set_id, embedder=impl.name, model=embedder.model, dim=dim,
            chunk_ids=[c.chunk_id for c in chunk_set.chunks],
        ))

    return _artifact_job(ctx, stage="embed_chunks", input_ids=[chunk_set_id], kind="vectors", impl=impl,
                         registry_kind="embedder", produce=produce)


def index_chunks(
    chunk_set_id: str, vector_set_id: str, entity_set_id: str | None = None, *, ctx: IngestContext
) -> JobResult:
    """Load chunks, vectors and entities into the search backend.

    The output lives in the database, not the artifact store, so "already done" is read from the
    job log (which lives in the same database and moves with it).
    """
    if ctx.backend is None:
        raise ValueError("index_chunks needs a search backend")
    impl, kb, backend = ctx.kb.index, ctx.kb.kb, ctx.backend
    input_ids = [chunk_set_id, vector_set_id] + ([entity_set_id] if entity_set_id else [])
    output_id = stable_id("index_chunks", input_ids, impl.name, backend.version, impl.params)

    def check(previous: JobRecord | None) -> str | None:
        done = previous and previous.status in ("succeeded", "skipped") and previous.output_id == output_id
        return output_id if done else None

    def work() -> str:
        chunk_set = ctx.store.read_model(kb, "chunks", chunk_set_id, ChunkSet)
        vector_set = ctx.store.read_model(kb, "vectors", vector_set_id, VectorSet)
        vectors = ctx.store.read_array(kb, "vectors", vector_set_id)
        if vector_set.chunk_ids != [c.chunk_id for c in chunk_set.chunks]:
            raise ValueError(f"vector set {vector_set_id} does not belong to chunk set {chunk_set_id}")
        entities: dict[str, set[str]] = defaultdict(set)
        if entity_set_id:
            for entity in ctx.store.read_model(kb, "entities", entity_set_id, EntitySet).entities:
                entities[entity.chunk_id].add(entity.normalized)
        if chunk_set.chunks:
            index = backend.ensure_index(kb, vector_set.embedder, vector_set.model, vector_set.dim,
                                         impl.params.get("text_search_language", "english"))
            backend.upsert([
                IndexRow(
                    chunk_id=c.chunk_id, doc_id=c.doc_id, position=c.position, text=c.text,
                    embedding=vectors[i].tolist(), source_uri=chunk_set.source_uri, title=chunk_set.title,
                    page_start=c.page_start, page_end=c.page_end, section_path=c.section_path,
                    entities=sorted(entities[c.chunk_id]), acl=c.acl, metadata=c.metadata,
                )
                for i, c in enumerate(chunk_set.chunks)
            ], index)
        return output_id

    return _run(ctx, stage="index_chunks", input_ids=input_ids, impl=impl, version=backend.version,
                check=check, work=work)


def run_stage(stage: str, input_ids: list[str], *, ctx: IngestContext) -> JobResult:
    """Run one job by stage name, e.g. from the CLI or when retrying a failed job."""
    if stage == "read_source":
        return read_source(SourceRef(uri=input_ids[0]), ctx=ctx)
    single = {
        "understand_document": understand_document,
        "chunk_document": chunk_document,
        "extract_entities": extract_entities,
        "embed_chunks": embed_chunks,
    }
    if stage in single:
        if len(input_ids) != 1:
            raise ValueError(f"{stage} takes exactly one input id")
        return single[stage](input_ids[0], ctx=ctx)
    if stage == "index_chunks":
        if len(input_ids) not in (2, 3):
            raise ValueError("index_chunks takes a chunk set id, a vector set id and optionally an entity set id")
        return index_chunks(*input_ids, ctx=ctx)
    raise ValueError(f"unknown stage {stage!r}; expected one of {STAGES}")
```

"""Runs every stage for each document in a source. One failing document never stops the batch."""

from __future__ import annotations

from collections import Counter
from collections.abc import Iterable
from concurrent.futures import ThreadPoolExecutor
from typing import Literal

from pydantic import BaseModel, Field

from mayakb.core import registry
from mayakb.core.contracts import SourceRef
from mayakb.ingest.jobs import (
    IngestContext,
    JobFailed,
    JobResult,
    chunk_document,
    embed_chunks,
    extract_entities,
    index_chunks,
    read_source,
    understand_document,
)


class DocumentOutcome(BaseModel):
    source_uri: str
    status: Literal["succeeded", "skipped", "failed"]
    failed_stage: str | None = None
    error: str | None = None
    jobs: list[JobResult] = Field(default_factory=list)


class IngestReport(BaseModel):
    kb: str
    documents: list[DocumentOutcome] = Field(default_factory=list)

    def counts(self) -> dict[str, int]:
        found = Counter(d.status for d in self.documents)
        return {status: found.get(status, 0) for status in ("succeeded", "skipped", "failed")}


def ingest_document(ref: SourceRef, *, ctx: IngestContext) -> DocumentOutcome:
    jobs: list[JobResult] = []
    try:
        jobs.append(read_source(ref, ctx=ctx))
        jobs.append(understand_document(jobs[-1].output_id, ctx=ctx))
        jobs.append(chunk_document(jobs[-1].output_id, ctx=ctx))
        chunk_set_id = jobs[-1].output_id
        with ThreadPoolExecutor(max_workers=2) as pool:
            embedding = pool.submit(embed_chunks, chunk_set_id, ctx=ctx)
            entities = pool.submit(extract_entities, chunk_set_id, ctx=ctx) if ctx.kb.ner else None
            vector_result = embedding.result()
            entity_result = entities.result() if entities else None
        jobs.append(vector_result)
        if entity_result:
            jobs.append(entity_result)
        jobs.append(index_chunks(chunk_set_id, vector_result.output_id,
                                 entity_result.output_id if entity_result else None, ctx=ctx))
    except JobFailed as exc:
        return DocumentOutcome(source_uri=ref.uri, status="failed", failed_stage=exc.stage,
                               error=f"{type(exc.cause).__name__}: {exc.cause}", jobs=jobs)
    status = "skipped" if all(job.status == "skipped" for job in jobs) else "succeeded"
    return DocumentOutcome(source_uri=ref.uri, status=status, jobs=jobs)


def ingest(ctx: IngestContext, refs: Iterable[SourceRef] | None = None) -> IngestReport:
    """Ingest every document the KB's connector lists (or the given refs)."""
    if refs is None:
        source = ctx.kb.source
        refs = registry.create("connector", source.name, **source.params).list()
    report = IngestReport(kb=ctx.kb.kb)
    for ref in refs:
        report.documents.append(ingest_document(ref, ctx=ctx))
    return report
```

```python
"""Merge dense and keyword hit lists into one ranked candidate list."""

from __future__ import annotations

from dataclasses import dataclass

from mayakb.core.config import RetrievalConfig
from mayakb.storage.search.base import Hit


@dataclass
class Candidate:
    hit: Hit
    fused_score: float
    dense_rank: int | None = None  # 1-based
    dense_score: float | None = None
    keyword_rank: int | None = None
    keyword_score: float | None = None
    rerank_score: float | None = None
    kept_by: str | None = None  # why the beam kept it

    @property
    def chunk_id(self) -> str:
        return self.hit.chunk_id


def _collect(dense: list[Hit], keyword: list[Hit]) -> dict[str, Candidate]:
    candidates: dict[str, Candidate] = {}
    for rank, hit in enumerate(dense, start=1):
        candidates[hit.chunk_id] = Candidate(hit=hit, fused_score=0.0, dense_rank=rank, dense_score=hit.score)
    for rank, hit in enumerate(keyword, start=1):
        candidate = candidates.setdefault(hit.chunk_id, Candidate(hit=hit, fused_score=0.0))
        candidate.keyword_rank = rank
        candidate.keyword_score = hit.score
    return candidates


def _ordered(candidates: dict[str, Candidate]) -> list[Candidate]:
    def best_rank(c: Candidate) -> int:
        return min(r for r in (c.dense_rank, c.keyword_rank) if r is not None)

    return sorted(candidates.values(), key=lambda c: (-c.fused_score, best_rank(c), c.chunk_id))


def rrf(dense: list[Hit], keyword: list[Hit], k: int = 60) -> list[Candidate]:
    """Reciprocal Rank Fusion: score = sum of 1 / (k + rank) over the lists a chunk appears in."""
    candidates = _collect(dense, keyword)
    for c in candidates.values():
        c.fused_score = sum(1.0 / (k + r) for r in (c.dense_rank, c.keyword_rank) if r is not None)
    return _ordered(candidates)


def _min_max(scores: dict[str, float]) -> dict[str, float]:
    if not scores:
        return {}
    low, high = min(scores.values()), max(scores.values())
    return {key: (s - low) / (high - low) if high > low else 1.0 for key, s in scores.items()}


def weighted(dense: list[Hit], keyword: list[Hit], dense_weight: float = 0.6) -> list[Candidate]:
    """Weighted sum of min-max normalized scores (a chunk missing from a list gets 0 there)."""
    candidates = _collect(dense, keyword)
    dense_norm = _min_max({h.chunk_id: h.score for h in dense})
    keyword_norm = _min_max({h.chunk_id: h.score for h in keyword})
    for chunk_id, c in candidates.items():
        dense_part = dense_weight * dense_norm.get(chunk_id, 0.0)
        c.fused_score = dense_part + (1 - dense_weight) * keyword_norm.get(chunk_id, 0.0)
    return _ordered(candidates)


def fuse(dense: list[Hit], keyword: list[Hit], config: RetrievalConfig) -> list[Candidate]:
    if config.fusion == "weighted":
        return weighted(dense, keyword, config.dense_weight)
    return rrf(dense, keyword, config.rrf_k)
```

```python
"""The dynamic beam (which fused candidates go to the reranker) and the final cut."""

from __future__ import annotations

from abc import ABC, abstractmethod
from collections import Counter
from dataclasses import dataclass, field

from mayakb.core.config import BeamConfig, CutConfig
from mayakb.core.text import count_tokens
from mayakb.retrieval.fusion import Candidate


@dataclass
class BeamSelection:
    beam: list[Candidate]  # in fused order
    rest: list[Candidate]  # fused candidates left out, in fused order
    kept_by: dict[str, int] = field(default_factory=dict)


class BeamPolicy(ABC):
    @abstractmethod
    def select(self, candidates: list[Candidate]) -> BeamSelection: ...


def _selection(candidates: list[Candidate], kept: list[Candidate]) -> BeamSelection:
    kept_ids = {c.chunk_id for c in kept}
    beam = [c for c in candidates if c.chunk_id in kept_ids]
    rest = [c for c in candidates if c.chunk_id not in kept_ids]
    return BeamSelection(beam=beam, rest=rest, kept_by=dict(Counter(c.kept_by for c in beam)))


class FixedBeam(BeamPolicy):
    """The baseline: the top `size` fused candidates."""

    def __init__(self, size: int = 30):
        self.size = size

    def select(self, candidates: list[Candidate]) -> BeamSelection:
        kept = candidates[: self.size]
        for c in kept:
            c.kept_by = "fixed"
        return _selection(candidates, kept)


class AdaptiveBeam(BeamPolicy):
    """Keep only candidates the cheap retrievers are confident about.

    A candidate is kept if both retrievers rank it in their top `agree_top`, or its dense score is
    within `dense_rel` of the best dense score, or its keyword score within `keyword_rel` of the
    best keyword score. Then at most `max_beam` are kept, topped up to `min_beam` in fused order.
    """

    def __init__(self, min_beam: int = 5, max_beam: int = 30, agree_top: int = 20,
                 dense_rel: float = 0.9, keyword_rel: float = 0.6):
        self.min_beam = min_beam
        self.max_beam = max_beam
        self.agree_top = agree_top
        self.dense_rel = dense_rel
        self.keyword_rel = keyword_rel

    def _reason(self, c: Candidate, best_dense: float | None, best_keyword: float | None) -> str | None:
        if (c.dense_rank is not None and c.keyword_rank is not None
                and c.dense_rank <= self.agree_top and c.keyword_rank <= self.agree_top):
            return "agreement"
        if best_dense and best_dense > 0 and c.dense_score is not None and c.dense_score >= self.dense_rel * best_dense:
            return "dense"
        if (best_keyword and best_keyword > 0 and c.keyword_score is not None
                and c.keyword_score >= self.keyword_rel * best_keyword):
            return "keyword"
        return None

    def select(self, candidates: list[Candidate]) -> BeamSelection:
        best_dense = max((c.dense_score for c in candidates if c.dense_score is not None), default=None)
        best_keyword = max((c.keyword_score for c in candidates if c.keyword_score is not None), default=None)
        kept: list[Candidate] = []
        for c in candidates:
            c.kept_by = self._reason(c, best_dense, best_keyword)
            if c.kept_by:
                kept.append(c)
        kept = kept[: self.max_beam]
        if len(kept) < self.min_beam:
            kept_ids = {c.chunk_id for c in kept}
            for c in candidates:
                if len(kept) >= self.min_beam:
                    break
                if c.chunk_id not in kept_ids:
                    c.kept_by = "top_up"
                    kept.append(c)
        return _selection(candidates, kept)


def make_beam(config: BeamConfig) -> BeamPolicy:
    if config.policy == "fixed":
        return FixedBeam(config.size)
    return AdaptiveBeam(config.min_beam, config.max_beam, config.agree_top, config.dense_rel, config.keyword_rel)


def cut(
    ranked: list[Candidate], config: CutConfig, token_budget: int, *, reranked: bool
) -> tuple[list[Candidate], bool]:
    """Choose the final chunks. Returns (selected, low_confidence).

    `ranked` is best first. When reranked, final k is the smallest of: items scoring >= min_score,
    items within relative_to_top of the best score, and items fitting the token budget; always at
    least min_k and at most max_k. low_confidence is true when nothing reaches min_score.
    """
    if not ranked:
        return [], False
    fits, used = 0, 0
    for c in ranked:
        used += count_tokens(c.hit.text)
        if used > token_budget:
            break
        fits += 1
    if not reranked:
        k = max(config.min_k, min(config.max_k, fits))
        return ranked[:k], False
    scores = [c.rerank_score or 0.0 for c in ranked]
    above_min = sum(1 for s in scores if s >= config.min_score)
    near_top = sum(1 for s in scores if s >= config.relative_to_top * scores[0])
    k = max(config.min_k, min(above_min, near_top, fits))
    k = min(k, config.max_k)
    return ranked[:k], above_min == 0
```

"""Cross-encoder reranker via sentence-transformers. Needs the `rerank` extra; runs on CPU by default."""

from __future__ import annotations

from typing import Any

from mayakb.retrieval.rerankers.base import Reranker


class CrossEncoderReranker(Reranker):
    name = "cross_encoder"
    version = "1"

    def __init__(
        self,
        model: str = "cross-encoder/ms-marco-MiniLM-L-6-v2",
        batch_size: int = 32,
        device: str | None = None,
        encoder: Any = None,
    ):
        if encoder is None:
            from sentence_transformers import CrossEncoder

            encoder = CrossEncoder(model, device=device)
        self.encoder = encoder
        self.batch_size = batch_size

    def score(self, query: str, texts: list[str]) -> list[float]:
        if not texts:
            return []
        import torch

        # Always apply a sigmoid: some models (e.g. ms-marco) are configured to return raw logits.
        scores = self.encoder.predict(
            [(query, text) for text in texts],
            batch_size=self.batch_size,
            activation_fn=torch.nn.Sigmoid(),
            show_progress_bar=False,
        )
        return [float(s) for s in scores]

```python
"""Turn the final candidates into result chunks: drop duplicates, merge neighbours, attach citations."""

from __future__ import annotations

from dataclasses import dataclass, field

from pydantic import BaseModel, Field

from mayakb.retrieval.fusion import Candidate


class Citation(BaseModel):
    source_uri: str
    title: str | None = None
    page_start: int | None = None
    page_end: int | None = None
    section_path: list[str] = Field(default_factory=list)


class ResultChunk(BaseModel):
    chunk_ids: list[str]  # more than one when neighbouring chunks were merged
    doc_id: str
    text: str
    rerank_score: float | None = None
    fused_score: float
    citation: Citation


@dataclass
class _Group:
    members: list[Candidate] = field(default_factory=list)

    @property
    def first(self) -> Candidate:
        return self.members[0]

    def positions(self) -> list[int]:
        return [m.hit.position for m in self.members]

    def adjacent(self, c: Candidate) -> bool:
        return (
            c.hit.doc_id == self.first.hit.doc_id
            and c.hit.section_path == self.first.hit.section_path
            and (c.hit.position == min(self.positions()) - 1 or c.hit.position == max(self.positions()) + 1)
        )


def _dedupe_key(text: str) -> str:
    return " ".join(text.lower().split())


def assemble(selected: list[Candidate]) -> list[ResultChunk]:
    """`selected` is best first. Results keep the rank of their best member."""
    seen: set[str] = set()
    groups: list[_Group] = []
    for c in selected:
        key = _dedupe_key(c.hit.text)
        if key in seen:
            continue
        seen.add(key)
        group = next((g for g in groups if g.adjacent(c)), None)
        if group is None:
            groups.append(_Group([c]))
        else:
            group.members.append(c)

    results = []
    for group in groups:
        members = sorted(group.members, key=lambda m: m.hit.position)
        pages_start = [m.hit.page_start for m in members if m.hit.page_start is not None]
        pages_end = [m.hit.page_end for m in members if m.hit.page_end is not None]
        rerank = [m.rerank_score for m in members if m.rerank_score is not None]
        top = group.first.hit
        results.append(ResultChunk(
            chunk_ids=[m.chunk_id for m in members],
            doc_id=top.doc_id,
            text="\n\n".join(m.hit.text for m in members),
            rerank_score=max(rerank) if rerank else None,
            fused_score=max(m.fused_score for m in members),
            citation=Citation(
                source_uri=top.source_uri,
                title=top.title,
                page_start=min(pages_start) if pages_start else None,
                page_end=max(pages_end) if pages_end else None,
                section_path=top.section_path,
            ),
        ))
    return results
```

def hit(chunk_id: str, score: float = 1.0, text: str | None = None, doc_id: str = "d1", position: int = 0,
        section_path: list[str] | None = None, page: int = 1) -> Hit:
    return Hit(
        chunk_id=chunk_id, doc_id=doc_id, position=position, text=text or f"text of {chunk_id}", score=score,
        source_uri=f"s3://docs/{doc_id}.md", title=doc_id.upper(), page_start=page, page_end=page,
        section_path=section_path if section_path is not None else ["S"],
    )


def candidate(chunk_id: str, *, dense_rank=None, dense_score=None, keyword_rank=None, keyword_score=None,
              rerank_score=None, text=None, **hit_kwargs) -> Candidate:
    return Candidate(
        hit=hit(chunk_id, text=text, **hit_kwargs), fused_score=0.0, dense_rank=dense_rank, dense_score=dense_score,
        keyword_rank=keyword_rank, keyword_score=keyword_score, rerank_score=rerank_score,
    )


def make_searcher(corpus, embedder=None, reranker=None, **retrieval) -> Searcher:
    """A Searcher over the `corpus` fixture; keyword args override retrieval config fields."""
    kb, backend = corpus
    if retrieval:
        kb = kb.model_copy(update={"retrieval": kb.retrieval.model_copy(update=retrieval)})

"""The retrieval pipeline: prepare -> hybrid retrieve -> fuse -> beam -> rerank -> cut -> assemble."""

from __future__ import annotations

import time
from collections.abc import Iterator
from concurrent.futures import ThreadPoolExecutor
from contextlib import contextmanager
from typing import Any, Literal

from pydantic import BaseModel, Field

from mayakb.core import registry
from mayakb.core.config import KBConfig
from mayakb.ingest.embedders.base import Embedder
from mayakb.retrieval.beam import cut, make_beam
from mayakb.retrieval.context import ResultChunk, assemble
from mayakb.retrieval.fusion import Candidate, fuse
from mayakb.retrieval.rerankers.base import Reranker
from mayakb.storage.search.base import Filters, Hit, IndexInfo, SearchBackend


class IndexNotFound(LookupError):
    pass


class SearchOptions(BaseModel):
    beam: Literal["adaptive", "fixed"] | None = None  # None = the KB config's policy
    rerank: bool = True
    token_budget: int | None = None
    retrievers: Literal["hybrid", "dense", "keyword"] = "hybrid"


class SearchResults(BaseModel):
    query: str
    chunks: list[ResultChunk]
    low_confidence: bool = False
    trace: dict[str, Any] = Field(default_factory=dict)


@contextmanager
def _timed(timings: dict[str, float], step: str) -> Iterator[None]:
    start = time.perf_counter()
    try:
        yield
    finally:
        timings[step] = round((time.perf_counter() - start) * 1000, 2)


def _error(exc: BaseException) -> str:
    return f"{type(exc).__name__}: {exc}"


class Searcher:
    def __init__(self, kb: KBConfig, backend: SearchBackend, embedder: Embedder, reranker: Reranker | None,
                 reranker_error: str | None = None):
        self.kb = kb
        self.backend = backend
        self.embedder = embedder
        self.reranker = reranker
        self.reranker_error = reranker_error

    @classmethod
    def from_config(cls, kb: KBConfig, backend: SearchBackend) -> Searcher:
        embedder = registry.create("embedder", kb.embed.name, **kb.embed.params)
        reranker, reranker_error = None, None
        if kb.retrieval.reranker is not None:
            try:
                reranker = registry.create("reranker", kb.retrieval.reranker.name, **kb.retrieval.reranker.params)
            except Exception as exc:  # e.g. model download failed: search still works, unreranked
                reranker_error = _error(exc)
        return cls(kb, backend, embedder, reranker, reranker_error)

    def _index(self) -> IndexInfo:
        index = self.backend.find_index(self.kb.kb, self.kb.embed.name, self.embedder.model)
        if index is None:
            available = [f"{i.embedder}:{i.model}" for i in self.backend.list_indexes(self.kb.kb)]
            raise IndexNotFound(
                f"no index for kb {self.kb.kb!r} with embedder {self.kb.embed.name}:{self.embedder.model}; "
                f"indexed: {available or 'nothing yet (run mayakb ingest)'}"
            )
        return index

    def _retrieve(self, query: str, vector: list[float] | None, use_keyword: bool, depth: int,
                  filters: Filters, index: IndexInfo) -> tuple[list[Hit], list[Hit]]:
        with ThreadPoolExecutor(max_workers=2) as pool:
            dense = keyword = None
            if vector is not None:
                dense = pool.submit(self.backend.dense_search, vector, depth, filters, index)
            if use_keyword:
                keyword = pool.submit(self.backend.keyword_search, query, depth, filters, index)
            return (dense.result() if dense else []), (keyword.result() if keyword else [])

    def _rerank(self, query: str, candidates: list[Candidate]) -> None:
        scores = self.reranker.score(query, [c.hit.text for c in candidates])
        if len(scores) != len(candidates):
            raise ValueError(f"reranker returned {len(scores)} scores for {len(candidates)} texts")
        for c, s in zip(candidates, scores, strict=True):
            c.rerank_score = s

    def search(
        self,
        query: str,
        filters: Filters | dict[str, Any] | None = None,
        options: SearchOptions | None = None,
        principals: list[str] | None = None,
    ) -> SearchResults:
        query = query.strip()
        if not query:
            raise ValueError("query is empty")
        options = options or SearchOptions()
        config = self.kb.retrieval
        beam_config = config.beam if options.beam is None else config.beam.model_copy(update={"policy": options.beam})
        token_budget = options.token_budget or config.token_budget
        filters = filters if isinstance(filters, Filters) else Filters(**(filters or {}))
        if principals is not None:
            filters = filters.model_copy(update={"principals": principals})
        filters = filters.normalized()
        timings: dict[str, float] = {}
        trace: dict[str, Any] = {"dense": False, "keyword": False, "reranked": False, "fallback_used": False,
                                 "timings_ms": timings}

        index = self._index()

        vector = None
        if options.retrievers in ("hybrid", "dense"):
            with _timed(timings, "embed"):
                try:
                    vector = self.embedder.embed_query(query)
                except Exception as exc:  # embedder down: keyword search still works
                    trace["dense_error"] = _error(exc)
        use_keyword = options.retrievers in ("hybrid", "keyword") or vector is None
        with _timed(timings, "retrieve"):
            dense_hits, keyword_hits = self._retrieve(query, vector, use_keyword, beam_config.depth, filters, index)
        trace["dense"], trace["keyword"] = vector is not None, use_keyword

        with _timed(timings, "fuse"):
            candidates = fuse(dense_hits, keyword_hits, config)
        with _timed(timings, "beam"):
            selection = make_beam(beam_config).select(candidates)

        ranked = list(selection.beam)
        reranked_count = 0
        if options.rerank and self.reranker is not None and ranked:
            with _timed(timings, "rerank"):
                try:
                    self._rerank(query, ranked)
                    reranked_count = len(ranked)
                    nothing_good = all(c.rerank_score < config.cut.min_score for c in ranked)
                    if beam_config.fallback_widen and nothing_good and selection.rest:
                        extra = selection.rest[: beam_config.max_beam]
                        self._rerank(query, extra)
                        reranked_count += len(extra)
                        ranked += extra
                        trace["fallback_used"] = True
                    ranked.sort(key=lambda c: -c.rerank_score)
                    trace["reranked"] = True
                except Exception as exc:  # reranker failed: keep fused order
                    trace["rerank_error"] = _error(exc)
                    trace["fallback_used"] = False
                    for c in candidates:
                        c.rerank_score = None
                    ranked, reranked_count = list(selection.beam), 0
        elif options.rerank and self.reranker_error:
            trace["rerank_error"] = self.reranker_error

        with _timed(timings, "cut"):
            selected, low_confidence = cut(ranked, config.cut, token_budget, reranked=trace["reranked"])
        chunks = assemble(selected)

        trace["counts"] = {
            "dense": len(dense_hits), "keyword": len(keyword_hits), "fused": len(candidates),
            "beam": len(selection.beam), "reranked": reranked_count, "final": len(chunks),
        }
        trace["beam"] = {
            "policy": beam_config.policy,
            "kept_by": selection.kept_by,
            "chunk_ids": [c.chunk_id for c in selection.beam],
            "doc_ids": sorted({c.hit.doc_id for c in selection.beam}),
        }
        return SearchResults(query=query, chunks=chunks, low_confidence=low_confidence, trace=trace)

"""Evaluation harness: score search quality and reranker cost on labelled queries.

queries.jsonl, one per line:
  {"query": "...", "relevant_chunk_ids": ["..."], "relevant_doc_ids": ["..."], "filters": {...}}
Chunk ids are used when given; otherwise document ids.
"""

from __future__ import annotations

import json
import math
import time
from pathlib import Path
from typing import Any

import numpy as np
from pydantic import BaseModel, Field

from mayakb.retrieval.search import Searcher, SearchOptions, SearchResults

VARIANTS: dict[str, SearchOptions] = {
    "fixed_beam": SearchOptions(beam="fixed"),
    "adaptive_beam": SearchOptions(beam="adaptive"),
    "adaptive_no_rerank": SearchOptions(beam="adaptive", rerank=False),
    "dense_only": SearchOptions(beam="adaptive", retrievers="dense"),
    "keyword_only": SearchOptions(beam="adaptive", retrievers="keyword"),
}


class EvalQuery(BaseModel):
    query: str
    relevant_chunk_ids: list[str] = Field(default_factory=list)
    relevant_doc_ids: list[str] = Field(default_factory=list)
    filters: dict[str, Any] | None = None


class EvalReport(BaseModel):
    variant: str
    queries: int
    beam_recall: float
    avg_beam_size: float
    recall_at_k: float
    ndcg_at_10: float
    mrr: float
    latency_p50_ms: float
    latency_p95_ms: float


def load_queries(path: str | Path) -> list[EvalQuery]:
    lines = Path(path).read_text(encoding="utf-8").splitlines()
    return [EvalQuery.model_validate(json.loads(line)) for line in lines if line.strip()]


def recall(retrieved: list[str], relevant: set[str]) -> float:
    return len(set(retrieved) & relevant) / len(relevant) if relevant else 0.0


def reciprocal_rank(flags: list[bool]) -> float:
    return next((1.0 / rank for rank, hit in enumerate(flags, start=1) if hit), 0.0)


def ndcg_at_10(flags: list[bool], relevant_count: int) -> float:
    dcg = sum(1.0 / math.log2(rank + 1) for rank, hit in enumerate(flags[:10], start=1) if hit)
    ideal = sum(1.0 / math.log2(rank + 1) for rank in range(1, min(relevant_count, 10) + 1))
    return dcg / ideal if ideal else 0.0


def _judge(q: EvalQuery, results: SearchResults) -> tuple[list[bool], set[str], list[str], list[str]]:
    """Per-result relevance flags, the relevant set, retrieved ids and beam ids (same id kind)."""
    if q.relevant_chunk_ids:
        relevant = set(q.relevant_chunk_ids)
        flags = [bool(set(c.chunk_ids) & relevant) for c in results.chunks]
        retrieved = [cid for c in results.chunks for cid in c.chunk_ids]
        beam = results.trace["beam"]["chunk_ids"]
    else:
        relevant = set(q.relevant_doc_ids)
        flags = [c.doc_id in relevant for c in results.chunks]
        retrieved = [c.doc_id for c in results.chunks]
        beam = results.trace["beam"]["doc_ids"]
    return flags, relevant, retrieved, beam


def evaluate(
    searcher: Searcher, queries: list[EvalQuery], options: SearchOptions, variant: str = "custom"
) -> EvalReport:
    if not queries:
        raise ValueError("no queries to evaluate")
    beam_recalls, beam_sizes, recalls, ndcgs, rrs, latencies = [], [], [], [], [], []
    for q in queries:
        start = time.perf_counter()
        results = searcher.search(q.query, filters=q.filters, options=options)
        latencies.append((time.perf_counter() - start) * 1000)
        flags, relevant, retrieved, beam = _judge(q, results)
        beam_recalls.append(recall(beam, relevant))
        beam_sizes.append(results.trace["counts"]["beam"])
        recalls.append(recall(retrieved, relevant))
        ndcgs.append(ndcg_at_10(flags, len(relevant)))
        rrs.append(reciprocal_rank(flags))
    return EvalReport(
        variant=variant,
        queries=len(queries),
        beam_recall=round(float(np.mean(beam_recalls)), 4),
        avg_beam_size=round(float(np.mean(beam_sizes)), 2),
        recall_at_k=round(float(np.mean(recalls)), 4),
        ndcg_at_10=round(float(np.mean(ndcgs)), 4),
        mrr=round(float(np.mean(rrs)), 4),
        latency_p50_ms=round(float(np.percentile(latencies, 50)), 2),
        latency_p95_ms=round(float(np.percentile(latencies, 95)), 2),
    )


def compare(searcher: Searcher, queries: list[EvalQuery]) -> list[EvalReport]:
    """Run every variant in VARIANTS on the same queries."""
    return [evaluate(searcher, queries, options, name) for name, options in VARIANTS.items()]

```python
"""Builds the real runtime from environment settings: Postgres, filesystem artifacts, KB config."""

from __future__ import annotations

from dataclasses import dataclass
from typing import Any

from psycopg_pool import ConnectionPool

from mayakb.core.config import KBConfig, Settings
from mayakb.ingest.jobs import IngestContext
from mayakb.retrieval.search import Searcher, SearchOptions, SearchResults
from mayakb.storage.artifacts import FileArtifactStore
from mayakb.storage.db import DatabaseUnavailable, make_pool
from mayakb.storage.joblog import JobLog, JobRecord, PostgresJobLog
from mayakb.storage.search.base import Filters, SearchBackend
from mayakb.storage.search.postgres import PostgresSearchBackend


@dataclass
class Runtime:
    settings: Settings
    kb: KBConfig
    store: FileArtifactStore
    joblog: JobLog
    backend: SearchBackend
    pool: ConnectionPool | None = None

    def context(self) -> IngestContext:
        return IngestContext(kb=self.kb, store=self.store, joblog=self.joblog, backend=self.backend)

    def searcher(self) -> Searcher:
        return Searcher.from_config(self.kb, self.backend)

    def close(self) -> None:
        if self.pool is not None:
            self.pool.close()


def load_kb(name: str, settings: Settings) -> KBConfig:
    path = settings.kb_config_path(name)
    if not path.is_file():
        raise FileNotFoundError(f"no config for knowledge base {name!r} at {path}")
    kb = KBConfig.from_yaml(path)
    if kb.kb != name:
        raise ValueError(f"{path} declares kb {kb.kb!r}; expected {name!r}")
    return kb


def open_pool(settings: Settings) -> ConnectionPool:
    if not settings.database_url:
        raise DatabaseUnavailable("MAYAKB_DATABASE_URL is not set")
    return make_pool(settings.database_url)


def build_runtime(kb_name: str, settings: Settings | None = None, pool: ConnectionPool | None = None) -> Runtime:
    settings = settings or Settings.from_env()
    kb = load_kb(kb_name, settings)
    if kb.index.name != "postgres":
        raise ValueError(f"index backend {kb.index.name!r} is not available; use 'postgres'")
    pool = pool or open_pool(settings)
    try:
        return Runtime(
            settings=settings,
            kb=kb,
            store=FileArtifactStore(settings.data_dir),
            joblog=PostgresJobLog(pool),
            backend=PostgresSearchBackend(pool),
            pool=pool,
        )
    except Exception:
        pool.close()
        raise


def find_job(job_id: str, settings: Settings | None = None) -> tuple[JobRecord, ConnectionPool]:
    """The job's record and an open pool the caller can reuse for build_runtime."""
    pool = open_pool(settings or Settings.from_env())
    record = PostgresJobLog(pool).get(job_id)
    if record is None:
        pool.close()
        raise LookupError(f"no job {job_id!r}")
    return record, pool


def search(
    query: str,
    kb: str,
    filters: Filters | dict[str, Any] | None = None,
    options: SearchOptions | None = None,
    principals: list[str] | None = None,
    settings: Settings | None = None,
) -> SearchResults:
    """One-shot search using environment settings. Long-running callers should keep a Runtime."""
    runtime = build_runtime(kb, settings)
    try:
        return runtime.searcher().search(query, filters=filters, options=options, principals=principals)
    finally:
        runtime.close()
```

```python
"""Command line: mayakb db init | ingest | run | jobs | retry | search | eval."""

from __future__ import annotations

import json
from collections.abc import Iterator
from contextlib import contextmanager
from pathlib import Path
from typing import Annotated

import typer
from psycopg_pool import ConnectionPool

from mayakb import wiring
from mayakb.core.config import Settings
from mayakb.ingest.jobs import JobFailed, run_stage
from mayakb.ingest.runner import ingest as run_ingest
from mayakb.retrieval.context import ResultChunk
from mayakb.retrieval.evaluate import compare, load_queries
from mayakb.retrieval.search import SearchOptions
from mayakb.storage.db import DatabaseUnavailable, apply_migrations
from mayakb.storage.search.base import Filters

app = typer.Typer(no_args_is_help=True, add_completion=False, help="mayaKB: ingest documents and search them.")
db_app = typer.Typer(no_args_is_help=True, help="Database commands.")
app.add_typer(db_app, name="db")

KbOption = Annotated[str, typer.Option("--kb", help="Knowledge base name; its config is configs/<kb>.yaml.")]

# Errors worth a one-line message instead of a traceback.
EXPECTED_ERRORS = (DatabaseUnavailable, FileNotFoundError, JobFailed, LookupError, ValueError)


def main() -> None:
    app()


def _fail(message: str) -> None:
    typer.echo(f"error: {message}", err=True)
    raise typer.Exit(code=1)


@contextmanager
def _runtime(kb: str, pool: ConnectionPool | None = None) -> Iterator[wiring.Runtime]:
    try:
        runtime = wiring.build_runtime(kb, pool=pool)
    except EXPECTED_ERRORS as exc:
        if pool is not None:
            pool.close()
        _fail(str(exc))
    try:
        yield runtime
    except EXPECTED_ERRORS as exc:
        _fail(str(exc))
    finally:
        runtime.close()


@db_app.command("init")
def db_init() -> None:
    """Create or upgrade the database schema. Safe to run repeatedly."""
    settings = Settings.from_env()
    if not settings.database_url:
        _fail("MAYAKB_DATABASE_URL is not set")
    try:
        applied = apply_migrations(settings.database_url)
    except DatabaseUnavailable as exc:
        _fail(str(exc))
    typer.echo(f"applied migrations: {', '.join(applied)}" if applied else "database schema is up to date")


@app.command()
def ingest(kb: KbOption) -> None:
    """Fetch, parse, chunk, tag, embed and index every new or changed document in the source."""
    with _runtime(kb) as rt:
        report = run_ingest(rt.context())
    for doc in report.documents:
        line = f"{doc.status:9} {doc.source_uri}"
        if doc.status == "failed":
            line += f"  [{doc.failed_stage}] {doc.error}"
        typer.echo(line)
    counts = report.counts()
    typer.echo(f"done: {counts['succeeded']} ingested, {counts['skipped']} unchanged, {counts['failed']} failed")
    if counts["failed"]:
        raise typer.Exit(code=1)


@app.command("run")
def run_job(
    stage: Annotated[str, typer.Argument(help="read_source, understand_document, chunk_document, "
                                              "extract_entities, embed_chunks or index_chunks")],
    input_ids: Annotated[list[str], typer.Argument(help="The stage's input ids (a uri for read_source).")],
    kb: KbOption,
) -> None:
    """Run one job, e.g. `mayakb run chunk_document <doc_model_id> --kb docs`."""
    with _runtime(kb) as rt:
        result = run_stage(stage, input_ids, ctx=rt.context())
    typer.echo(result.model_dump_json(indent=2))


@app.command()
def jobs(
    kb: KbOption,
    status: Annotated[str | None, typer.Option(help="pending, running, succeeded, failed or skipped")] = None,
    limit: Annotated[int, typer.Option(help="How many to show, newest first.")] = 50,
) -> None:
    """List recent jobs."""
    with _runtime(kb) as rt:
        records = rt.joblog.list(kb, status=status, limit=limit)
    for r in records:
        typer.echo(f"{r.job_id}  {r.status:9}  {r.stage:20}  attempts={r.attempts}  {r.error or ''}".rstrip())
    if not records:
        typer.echo("no jobs")


@app.command()
def retry(job_id: str) -> None:
    """Run a job again with the same inputs, e.g. after fixing whatever made it fail."""
    try:
        record, pool = wiring.find_job(job_id)
    except EXPECTED_ERRORS as exc:
        _fail(str(exc))
    with _runtime(record.kb, pool=pool) as rt:
        result = run_stage(record.stage, record.input_ids, ctx=rt.context())
    typer.echo(result.model_dump_json(indent=2))


def _describe(rank: int, chunk: ResultChunk) -> str:
    c = chunk.citation
    pages = ""
    if c.page_start is not None:
        pages = f" p.{c.page_start}" + (f"-{c.page_end}" if c.page_end not in (None, c.page_start) else "")
    score = f"{chunk.rerank_score:.2f}" if chunk.rerank_score is not None else "-"
    text = " ".join(chunk.text.split())
    snippet = text[:300] + ("…" if len(text) > 300 else "")
    return f"[{rank}] score={score}  {c.source_uri}{pages}  {' > '.join(c.section_path)}\n    {snippet}"


@app.command()
def search(
    query: str,
    kb: KbOption,
    source_prefix: Annotated[str | None, typer.Option(help="Only documents whose uri starts with this.")] = None,
    entity: Annotated[list[str] | None, typer.Option(help="Only chunks tagged with this entity. Repeatable.")] = None,
    principal: Annotated[list[str] | None, typer.Option(help="Reserved: search as this principal. Repeatable.")] = None,
    beam: Annotated[str | None, typer.Option(help="adaptive or fixed (default: from the KB config)")] = None,
    no_rerank: Annotated[bool, typer.Option("--no-rerank", help="Skip the reranker.")] = False,
    trace: Annotated[bool, typer.Option("--trace", help="Also print counts, beam and timings.")] = False,
    as_json: Annotated[bool, typer.Option("--json", help="Print the whole result as JSON.")] = False,
) -> None:
    """Hybrid search with the dynamic beam and reranker."""
    with _runtime(kb) as rt:
        options = SearchOptions(beam=beam, rerank=not no_rerank)
        filters = Filters(source_prefix=source_prefix, entities=entity or None)
        results = rt.searcher().search(query, filters=filters, options=options, principals=principal or None)
    if as_json:
        typer.echo(results.model_dump_json(indent=2))
        return
    if results.low_confidence:
        typer.echo("(low confidence: nothing scored above the rerank threshold)")
    for rank, chunk in enumerate(results.chunks, start=1):
        typer.echo(_describe(rank, chunk))
    if not results.chunks:
        typer.echo("no results")
    if trace:
        typer.echo(json.dumps(results.trace, indent=2))


@app.command("eval")
def eval_command(
    kb: KbOption,
    queries: Annotated[Path, typer.Option(exists=True, dir_okay=False, help="Labelled queries, one JSON per line.")],
    as_json: Annotated[bool, typer.Option("--json", help="Print the reports as JSON.")] = False,
) -> None:
    """Compare fixed vs adaptive beam, reranker on/off, and dense/keyword/hybrid retrieval."""
    with _runtime(kb) as rt:
        reports = compare(rt.searcher(), load_queries(queries))
    if as_json:
        typer.echo(json.dumps([r.model_dump() for r in reports], indent=2))
        return
    typer.echo(f"{'variant':20} {'beam_recall':>11} {'avg_beam':>8} {'recall@k':>8} {'ndcg@10':>7} {'mrr':>6} "
               f"{'p50_ms':>7} {'p95_ms':>7}")
    for r in reports:
        typer.echo(f"{r.variant:20} {r.beam_recall:>11.3f} {r.avg_beam_size:>8.1f} {r.recall_at_k:>8.3f} "
                   f"{r.ndcg_at_10:>7.3f} {r.mrr:>6.3f} {r.latency_p50_ms:>7.1f} {r.latency_p95_ms:>7.1f}")
```

`README.md` (replaces the whole file):

````markdown
# mayaKB

A knowledge base you can run anywhere Docker runs. Documents go through separate, re-runnable
ingestion jobs; search is hybrid (vector + keyword) with a dynamic beam and a reranker, and every
result carries a citation (file, pages, section).

Design: [`docs/specs/2026-09-16-mayakb-design.md`](docs/specs/2026-09-16-mayakb-design.md)

## How it works

**Ingestion** runs six jobs per document. Each is a plain Python function behind a swappable
interface, saves its output, and is skipped when that output already exists:

| Job | Interface | Built in |
|---|---|---|
| `read_source` | Connector | `local`, `s3` |
| `understand_document` | Parser | `local` (PDF, DOCX, Markdown, text), `llamaparse` |
| `chunk_document` | ChunkingStrategy | `fixed`, `by_section` |
| `extract_entities` | EntityExtractor | `spacy` |
| `embed_chunks` | Embedder | `ollama` |
| `index_chunks` | SearchBackend | `postgres` (pgvector + full-text search) |

**Retrieval**: vector and keyword search run in parallel with filters inside the SQL, results are
merged with Reciprocal Rank Fusion, the **dynamic beam** keeps only the candidates both searches are
confident about, only those go to the **reranker**, and a final cut picks how many to return.

## Run with Docker

```sh
cp .env.example .env          # set POSTGRES_PASSWORD
cp configs/example.yaml configs/docs.yaml   # edit: kb: docs, and your source
docker compose up -d          # db + ollama (pulls nomic-embed-text on first start)
docker compose build app
docker compose run --rm app mayakb ingest --kb docs
docker compose run --rm app mayakb search "How long do refunds take?" --kb docs --trace
```

Three containers: `app` (Python), `ollama`, `db` (Postgres + pgvector). No ports are published;
Postgres and Ollama are reachable only inside the compose network. Files for the `local` connector go
in `./sources` (mounted read-only at `/sources`).

**macOS:** Docker can't use the Apple GPU, so run Ollama natively (`ollama serve`) and in `.env` set
`COMPOSE_PROFILES=` and `MAYAKB_OLLAMA_URL=http://host.docker.internal:11434`.

**AWS EC2:** install Docker and the compose plugin, copy the repo and `.env`, then the same commands.
S3 access uses the instance's IAM role (no keys in `.env`). On GPU instances add
`-f docker-compose.gpu.yml`. Data lives in Docker volumes on the instance disk: back up with
`pg_dump` plus a copy of the `artifacts` volume. To use RDS instead of the `db` container, point
`MAYAKB_DATABASE_URL` at RDS (pgvector is supported there).

End-to-end check: `scripts/smoke.sh`.

## CLI

```
mayakb db init                                   create/upgrade the schema (runs on container start)
mayakb ingest --kb <kb>                          all stages for new or changed documents
mayakb run <stage> <input ids...> --kb <kb>      one job
mayakb jobs --kb <kb> [--status failed]          recent jobs
mayakb retry <job_id>                            re-run a job
mayakb search "<query>" --kb <kb> [--source-prefix P] [--entity E] [--beam fixed] [--no-rerank] [--trace] [--json]
mayakb eval --kb <kb> --queries queries.jsonl    fixed vs adaptive beam, reranker on/off, dense/keyword/hybrid
```

Knowledge bases are configured in `configs/<kb>.yaml` (see `configs/example.yaml`). Connection
details and secrets come only from environment variables: `MAYAKB_DATABASE_URL`, `MAYAKB_OLLAMA_URL`,
`MAYAKB_DATA_DIR`, `MAYAKB_CONFIGS_DIR`, `LLAMA_CLOUD_API_KEY`.
